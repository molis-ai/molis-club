# B 首页：围桌的人与大字标

## 目标与现状
用户希望 B 首页借用 A 首屏的大字标构图，将“给想法，一个生长的地方”和工作室介绍缩小、上移，并用 A 围桌讨论插画中的人物重新画背景。当前上一轮误把旧图的手绘媒介也沿用；用户已纠正：保留围桌交流内容，用 B 版的新风格重绘。完成等级：功能可用，沿用原私有发布。

## 保留、替换与范围
保留 A 全部页面、B 下方图组/交互与真实内容。B 首页背景替换为新绘横幅；原窗边图继续用于首页下方 Elsewhere 精选与现有详情。仅修改 B 首页首屏、对应页头色彩、资产与设计文档；其他栏目首屏继续原摄影版式。

## 构图与实现
- 上方偏中位置小字介绍，降低字号与视觉重量；入口改为轻量文字链接。
- 底部默认显示大幅可选择、可访问的 HTML `Molis AI` 字标，作为唯一 h1；无需鼠标或滚动才能看见。
- 原围桌插画只作为内容参考：四位创作者围桌交流，以及桌面小牛、小机器人等创作物。以 B 版 threshold 的自然窗光、灰绿墙、亚麻、浅木、电影感摄影作为媒介和材质参考，生成全新的真实空间画面。去掉旧版纸面手绘与羽化画框；首页改用整幅摄影背景，继续小字居上、底部大字标。图片不画入网页文字，生成人物不冒充真实团队肖像。
- 复用既有轻微鼠标/滚动反馈；文字不随鼠标移动；减少动态时静止。
- 手机保持介绍、人物、完整字标的顺序，调整画面尺寸与位置，避免字标压住面孔。

## 输入输出与依赖
内容参考 `public/images/molis-makers-studio.png`，风格参考 `public/images/atelier/threshold.jpg`；内置 imagegen 生成新图并压缩至站点素材。输出新横幅、B 首页构图、更新比较预览。依赖现有字体、Photo、AtelierMotion 与版本内 Link，不更改后台、数据与访问权限。

## 验收
桌面与手机首屏能同时看到小字介绍、人物及底部完整字标；标题唯一，图片实际加载且人物/字标不碰撞。窗边图仍可从首页下方看到。B 内页不继承首页小字与大字标。检查 hover/reduced-motion、版本内导航；执行 npm run check、定向 HTTP 和构建；发布原私有站点。

## 假设与边界
用户明确：用新风格画旧内容。保留四人围桌的主题，替换为 B 版自然光摄影语言，旧图线条、水彩、纸面不再作为风格约束。只生成一张首屏需要的新图，不改变 A 原图；背景选取及色彩承托随新照片适配。
