# Folio：molis.ai 工作室首页

状态：2026-10-10 按用户要求，将基于 `main · c28bfde8` 的 Folio 改动整理为「首页」与「站内页面与体验」两个本地提交，只提交、不推送、不发布。四条首页简介已由用户选定；整体视觉与真实手机手感仍待验收。历史检查按日期保留，本次提交复核见文末。依据是用户与一骏 2026-10-09 关于 molis.ai 首页的讨论及后续纠正。根目录 [handoff.md](../../handoff.md) 第四节要求「首屏说清楚业务与产品」，与这次讨论冲突，首页以本文件为准；handoff 中保留原版设计、团队顺序等其余要求继续有效。

## 讨论要点

- 现在的「把工作做轻，把时间还给生活。」太像喊口号。高端的愿景不靠口号，靠内容和网页设计；好用的产品也不靠介绍，靠产品自己。
- 首页要 B 格高、有质感、简约。第一页看着舒适，用关键词即可，参考字节的 “Inspire Creativity, Enrich Life”。
- 恢复一骏原来的 A/I 词组变体：这是团队介绍页，不是产品介绍页。
- 往下滑依次是产品陈列、团队介绍、我们的文章，然后是登录和社区。
- 这个站给老板看，也供我们演讲时使用。
- 几个域名各有主题和表现重点：统一风格，不统一内容和样式。

## 三个域名的分工

| 域名       | 给谁、什么场景                   | 主页重点                                           |
| ---------- | -------------------------------- | -------------------------------------------------- |
| molis.ai   | 老板、合作方，我们对外演讲时打开 | 工作室是谁：作品、团队、文章，要有质感             |
| molis.work | 想用产品的人                     | 产品怎么用：Work 为主，Tool 等也放进来，用跳链进入 |

三站共用暖纸、衬线大字与剪纸色块的风格，内容与版式各自设计。这是职责划分，不表示三个域名均已上线。最初方案只涉及 molis.ai 首页；后续已授权扩展到 Folio 站内路由、百科、Work 后半段、Solutions，以及联系页与社区的一致性收尾，具体边界见文末。

## 页面顺序

当前首页：首屏 → 产品 → 社区与登录／合作。2026-10-10 用户在首页批注要求移除团队与文章两块，并确认保留导航入口、分别进入独立页面。此前「首屏 → 产品 → 团队 → 文章 → 社区与登录」为原版顺序，已由本次决定替代。

### 2026-10-10 登录入口跳转崩溃修复

- 用户报告点击登录出现 `process is not defined`，浏览器堆栈指向预构建的 Vinext `stageAppNavigationFailureTarget`。当前 Vite 8.2.2 的依赖优化器没有继承客户端 `define`，Vinext 1.0.0-beta.9 只向它传递部分常量，导致路由依赖仍读取浏览器的 `process.env`。刷新后可以暂时恢复，不能据此认为缺陷已消失。
