### 首页一、二屏是什么风格

- **题材**：天、云、海、地平线，开阔的远景，画面大半是空的。
- **光**：日落前后的低角度光，亮处暖桃杏色，暗处雾蓝灰；暖的那一点正好接上站里的杏色。
- **色调**：低饱和、低对比、带一层雾，像胶片（高光暖、阴影冷）。
- **构图**：地平线放平，主体不在正中，字直接放在空处。
- **人**：没有，或远处很小的一两个，只给画面一个尺度——就是「技术，回到人的尺度」。
- **动**：慢。云按 0.24 倍、海按 0.55 倍慢放。

摄影里这一路是极简风景（留白风景）：黄金时刻到蓝调时刻的光，胶片色。

### A 的图片语言（替换第 6 节 A 原来那条）

- 两类画面，同一种光和色：
  - **户外**：天、云、海、地平线、远山、雾。
  - **室内**：空间和光——空房间、窗、墙上的光斑、窗外的天色。
- 不拍手、不拍脸；人只在远处、很小。
- 不要高调纯白、正午硬光、物件特写、科技感、插画、超现实或一眼看得出的生成感。
- 「实景」按画面说，不按出处说：二屏海边是拿一张 Unsplash 海边照片做参考、AI 生成的视频（`docs/site-media-audit-2026-10-16.md`），看上去和实拍无异。所以规则写「现实里拍得到的画面」，不写「只用实拍」。

## 2. 参考稿：同一把尺子量九张

尺子：第一眼感受、得到了什么信息、元认知（字号层级与字体、栅格与对齐、留白与密度、色彩与明暗节奏、产品界面呈现、段间过渡与整页一致性、图像与插画、动效、信息顺序），最后是能不能用在我们这里。只借原则，不用它们的素材、插画和品牌元素。

### Sparkline（数据平台，Analytics）
- 第一眼：干净、亮，很标准的 SaaS。
- 信息：一个面向 AI 的数据平台，三屏之内说完「是什么、怎么做、多少人在用」。
- 元认知：标题居中、两行、特大号，一个词铺黄色高亮，下面一行小字和一颗按钮，层级只有三档；每一段都是同一张圆角白纸浮在浅灰底上，段与段是「换一张纸」，所以整页很整；产品界面几乎不出现，拿三维小图标代替；社区一段突然换成整块黑底，节奏断了一下。
- 能用：**每段同一种容器**（同一张圆角纸）这件事能用；标题里只强调一处能用（我们用深浅，不用荧光色）。三维图标、整块黑底不用。

### CoreShift（人力资源平台）
- 第一眼：友好、有秩序。
- 信息：一个平台把人和常用工具连起来。
- 元认知：几乎每屏都是居中的一个焦点，周围环绕小头像和应用图标，用连线串起来；整页底色是一层很淡的紫灰，所有区块落在同一个环境里；页尾一个占满宽度的大字标。
- 能用：一屏一个居中焦点、整页一个环境；页尾大字标我们已经有。连线、环绕图标（DESIGN.md 已禁连接线），真人头像当装饰都不用。

### Wollo（社交媒体分析）
- 第一眼：吵，紫色、三维、霓虹折线。
- 信息：社媒数据分析，靠插画和图表撑场面。
- 元认知：插画承担了大部分视觉，产品界面被做成彩色卡片碎片；标题里嵌表情小图；FAQ 收尾。
- 能用：基本不能。它是一个反面参照：插画一多，调性立刻离开「安静」。

### Xurya（太阳能）
- 第一眼：可信、真实。
- 信息：做什么、为谁做、怎么保证质量，靠实拍的人和现场讲。
- 元认知：**两色标题**（前半句墨色、后半句灰，一句话里就有主次）；照片放在圆角矩形里，有真人在工作；一种强调色（绿）只给按钮；收尾一条深色带。
- 能用：两色标题、实拍的人在做事、强调色只给一处。绿色按钮、合作方标志排、统计数字不用（我们没有可写的数字）。

### Clause（合同管理）
- 第一眼：稳重，深绿品牌色。
- 信息：一个工具管合同和团队，能接各种现成软件。
- 元认知：居中标题加漂浮头像，深绿整块面板放集成图标墙，一排大数字；版式是熟悉的 SaaS 模板。
- 能用：「品牌色整块面板只出现一次、用来讲一件事」可以借（我们讲外部 AI 接入时）。其余是模板。

### HackerRank（开发者平台，视频）
- 第一眼：自信，有电影感。
- 信息：「开发的未来是人 + AI」，然后一路进入产品。
- 元认知：黑底上两行细体大字；往下滚，**一块设备屏幕一直在画面中央**，背景是一大片饱和绿，屏幕里的内容一段段换——容器不变、内容在变，整页没有割裂；真人照片和界面浮卡叠在一起。
- 能用：一个始终在场的容器、靠镜头和内容变化做段间过渡（我们首屏推近成全景已经在这么做）；真实照片配界面。黑底、荧光绿不用。

### reel.ai 类 AI 营销页（ai-landing）
- 第一眼：模板化。
- 信息：AI 帮你涨转化。
- 元认知：衬线大标题居中，一部手机里一张笑脸，四周漂浮数据小卡。
- 能用：几乎不能。漂浮数据卡是噪音，正好说明「窗外不要放零碎」。

### Milkinside 为 Cyft 做的页面（视频）
- 第一眼：昂贵，产品像一件物件。
- 信息：一个 AI 金融软件，所有功能都在同一块屏幕里讲。
- 元认知：一台显示器立在一面有质地的灰墙前，镜头绕着它移动、推近，屏幕里换内容；整页只有一个环境、一个物件；字很少，都在屏幕里。
- 能用：**一个环境、一个物件、段间过渡是镜头移动**——证明我们首屏推近成全景的方向对。深蓝科幻调、水泥阴郁感不用。

### Superlinked（向量计算）
- 第一眼：有触感、优雅、亮。
- 信息：一套界面，靠橙色细线讲数据怎么流动。
- 元认知：一台笔记本放在揉皱的银白材质上，软而亮的材质衬硬的界面；只有一种强调色（橙，和我们的杏色接近）；镜头不动，界面自己演。
- 能用：**软的实物衬硬的界面**（就是负责人 10-30 说的「软的照片对硬的界面才有质感」）、浅色调里只有一点暖色。笔记本样机不用（我们直接给窗口）。

### 九张合起来，对我们有用的原则

| 维度 | 参考里成熟的做法 | 用在我们这里 |
| --- | --- | --- |
| 字号层级 | 三到四档，档差大；标题里只强调一处 | 名字 / 屏标题 / 导语 / 小字四档；两色标题 |
| 栅格与对齐 | 一条左边缘或一根中轴，整页不变 | 所有字对齐同一条左边缘；字 + 窗的屏一律左 4 栏右 8 栏 |
| 留白与密度 | 一屏一件事，四周留白比内容多 | 一屏一段，窗外不放零碎 |
| 色彩与明暗 | 一种强调色；明暗变化有理由 | 杏色只做点；深色只在有理由时出现 |
| 产品界面 | 界面是主角，大、居中、完整 | 窗口完整出现在首屏，不被折线切 |
| 段间过渡 | 同一种容器贯穿，换内容不换容器 | 选一种容器（台面 / 墙 / 满版的光），全站用到底 |
| 图像 | 实拍、一组一个调子；或者完全不用 | 一种图片语言，撤掉混在一起的多种媒介 |
| 动效 | 镜头移动、界面自己演，不靠漂浮装饰 | 保留开窗、落定、推近、演示四种 |
| 信息顺序 | 是什么 → 怎么用 → 为什么是它 → 去哪 | 现在的顺序是对的，不动 |

## 3. 现在的 Work 页（main 版，同一把尺子）

- **第一眼**：首屏有照片、有窗口，质感比上一版好；往下看像五个团队做的五段。
- **得到的信息**：「工作，不止于 AI 对话」加一句是什么，能明白是一张 AI 工作台；但首屏窗口在 1440×900 只露出上面六成，「等你两件」这个结论落在折线下面。
- **字号层级**：首屏开场句约 40px，结尾「判断归人，执行可以托付。」约 68px，是全页最大的字——高潮落在了结尾，不在开头；五个屏标题用了三种大小；首屏英文口号和中文开场说同一件事。
- **栅格与对齐**：首屏字从版心边起，全景标题往里缩了一截，为什么一段的字在深色面板里又缩一截，左边缘断了三次。
- **留白与密度**：全景和用起来都很满；为什么一段左边四条差异加右边节点图，同时有两处要看。
- **色彩与明暗**：纸色 → 纸色 → 浅灰 → 突然一块深棕黑展台 → 照片。深色没有动机，切得突兀（负责人 10-30 已说过）。
- **产品界面**：首屏和全景的窗已经对齐；「用起来」的窗是另一套圆角和影子；「为什么」不是窗，是一张圆形头像加连线的示意图，成熟度明显低于窗口本身。
- **段间过渡与一致性**：五段五种舞台（照片舞台、纸上大窗、浅灰底、深色展台、照片里浮卡）；五种选择器（全景段落条、角色分段按钮、闭环小卡、五步竖线圆点、为什么的点亮列表）；「示意」标注四个位置（窗下左、窗下右、面板右下、卡片里）。
- **图像**：两张生成摄影（叶影墙木桌、窗边读书的人）调子好，但和全站其他图不是一家（见下一节）。窗外的菜单栏胶囊浮在照片上，读不出是什么。
- **动效**：首屏落定、推近成全景、各段演示都在，是这一页最强的部分，保留。
- **信息顺序**：是什么 → 全景 → 用起来 → 为什么 → 去哪，顺序对，不动。

结论：内容和动效不缺，**缺的是一套贯穿全页的容器、字阶和选择器**。每一段单看都有道理，放在一起没有共同的规矩。

## 5. 不管选哪个方向都做的共同规则

1. **字阶四档**：产品 / 品牌名（Jost 300，52–96px）> 屏标题（28–44px）> 副标题与导语（15.5–25px）> 小字（12–13px）。每页最大的字在第一屏。
2. **两色标题**：标题按标点分句，前面铺垫是灰，最后一句落点是墨色（「工作，」灰、「不止于 AI 对话。」墨）。只靠深浅，不加颜色。
3. **一种窗口**：所有产品窗口同一个尺寸单位（窗宽的 1/64）、同一个圆角、同一道暖色落地影子；终端、浮层跟着同一单位。
4. **一种选择器**：纯文字。选中的是墨色并展开一行说明，其余是灰；不用框、分段按钮、小卡、竖线、圆点。全景的段落条、用起来的角色 / 闭环 / 五步、为什么的四条都换成这一种。
5. **示意标注固定在窗口下沿、左对齐**，全站同一位置。
6. **一条左边缘**：所有字对齐版心边；字 + 窗的屏一律左 4 栏字、右 8 栏窗，字永远在左。
7. **一屏一段**，窗口在 1440×900 和 1280×800 都完整出现。
8. **窗外不放零碎**：去掉菜单栏胶囊；终端留下（它讲的是「你自己的 AI 接着同一份工作」）。
9. **待负责人点头的两处内容调整**：去掉首屏英文口号（和中文开场重复；10-30 定的，需要负责人改口）；「用起来」的角色 × 闭环两层选择，并成一列四个 case（少一层选择，左栏只剩一种选择器）。

## 6. 三个方向

三个方向共用上面的字阶、窗口和选择器，**只换容器和图片语言**。样稿每个方向四屏：Work 首屏、Work 用起来、Work 为什么是 Molis、首页首屏（看它铺到别的页的样子）。

### A 台面

**每屏一块大圆角台面，产品端端正正放在台面中央。**

- **容器**：台面圆角 28px，离屏幕边一指宽（20px），比版心宽一点，字在台面外的纸上、对齐版心。台面上只放一样东西：一扇窗、一张照片、一件作品。
- **台面的底**：和首页一、二屏同一路的风景或空间照片（见第 0 节），或者一层浅灰（`paper-2`）。首屏、换段的屏用照片，内容密的屏用浅灰。
- **色彩与明暗**：全站纸色，不出现深色段；节奏靠「纸 / 照片台面 / 浅灰台面」交替。
- **段间过渡**：台面是贯穿全站的容器；首屏推近成全景，就是窗从照片台面挪到浅灰台面上。
- **首屏一眼看懂**：上面一行字（名字、开场、是什么、报名），下面一块光的台面，窗口完整、居中，终端压在左边。
- **图片语言**：（10-31 改为第 0 节那条）原提案是「实拍的光落在白墙、纸、木桌和手上，高调暖白」。
- **铺到全站**：
  - 首页：一、二屏原样保留（满版的天与海）；产品列表的舞台就是台面。
  - Tool：Mac 屏幕放在台面上；壁纸换成同一组光影照片，或者保留莫奈当「屏幕里的东西」。
  - 企业合作：长廊、长桌两张换成同组实拍；四本书立在浅灰台面上。
  - 社区：作品放在台面上；首屏插画换成同一路的风景或空间；社区作品本身（AI 创作试样、插画）是展品，不受图片语言限制。
  - 关于：四间展厅的墙色保留，展品放在台面上；生成摄影和渲染撤下。
  - Life / Story / World、登录、404：概念画面放在浅灰台面上，不用照片。
- **代价与风险**：最接近成熟 SaaS 的通用做法（Sparkline、CoreShift 都是一张纸 / 一块面贯穿），辨识度主要靠照片；一组同色调的黄昏风景与空间照片要逐张挑，必要时统一调色。
- **和 DESIGN.md**：不冲突，只新增「台面」这一个容器。

### B 展墙

**每屏是一面墙，一件东西挂在墙上，旁边一张展签；配图是公有领域的画。**

- **容器**：没有台面、没有满版。每屏换一面墙（亚麻、白、月白、晨雾——「关于」现有的四种墙色延伸到全站），窗口、画、作品都「挂」在墙上：四周大留白，一道贴墙的短影子。
- **画怎么挂**：细深色框加白卡纸，不裁、不铺满，像真的挂着；画旁一张展签（作者、作品名、年份、馆藏）。
- **色彩与明暗**：全亮，墙色轮换代替明暗起伏。
- **段间过渡**：从一面墙走到另一面墙，像在展厅里换一间。
- **首屏一眼看懂**：左上名字和开场，左下是什么和报名，右边一扇窗挂在亚麻墙上，窗下一张展签。
- **图片语言**：公有领域的油画——丹麦黄金时代与 Hammershøi、Ilsted、Holsøe 一路的室内与光（窗、读写的人、空房间里的阳光），来自丹麦国立美术馆（SMK）等开放馆藏；照片只拍展厅本身。不要生成图、视频天空、插画。
- **铺到全站**：
  - 首页：首屏一幅画挂在墙上，旁边 Molis AI 大字和「技术，回到人的尺度。」；产品列表是一排挂在墙上的产品窗口。
  - Tool：Mac 屏幕挂在墙上，莫奈壁纸正好对上这一路。
  - 企业合作：长廊、长桌换成画（人在桌边一起做事的画）。
  - 社区：本来就是画廊，换掉动漫插画首屏。
  - 关于：已经是展厅，直接对齐。
- **代价与风险**：好画偏暗偏旧（Hammershøi 是灰调），亮的要专门挑；画和产品窗口并排，容易读成「博物馆」而不是「工作台」；展签是一种副标签——只能给画和作品用，产品窗口只留示意，否则和「少放副标签」冲突。
- **和 DESIGN.md**：概念（白房子 + 展厅 + 展签）本来就有，改动最小；需要把墙色从「关于」扩到全站。

### C 满版的光

**每屏一张满版照片（一天里的某个时刻），窗口浮在光里。**

- **容器**：首屏、换段和结尾是满版照片，字压在照片暗的一侧、白字；内容密的屏放在照片上的一张半透明纸里；夜里那屏全深色，窗口切深色主题。
- **色彩与明暗**：晨（暗室里的一束光）→ 午（纸）→ 夜（深）→ 晨（窗外海面），明暗起伏最大。
- **段间过渡**：时间推移，一页是一天。
- **首屏一眼看懂**：满屏一束光照进暗室，左边白字，右边一扇大窗。
- **图片语言**：电影感摄影，暗室、逆光、窗外天色、日出日落，高对比。不要生成图。
- **铺到全站**：每页一个时刻——首页是清晨窗外的海，Tool 是白天，企业合作是正午的长桌，社区是傍晚的画室，关于是夜里。
- **代价与风险**：冲击力最强，也离「安静」最远；满版日落很容易落进图库味；白字压图要逐张调对比度；负责人 10-30 试过把照片铺满一屏当背景，说「更吵、更丑」。
- **和 DESIGN.md**：冲突最多——要放开磨砂玻璃、渐变遮罩和整段深色。

## 7. Dribbble 的 SaaS 风格和我们安静的画廊调性

参考稿里成熟的东西大多是**结构**：一种容器贯穿、一屏一个焦点、标题档差大、产品界面当主角、镜头式过渡。这些和安静不冲突，反而是安静的前提——少即是整。会伤调性的是它们的**表面**：饱和品牌色、三维图标、霓虹图表、漂浮数据卡、合作方标志墙、大数字、整块黑底。

三个方向在这条线上的位置：

- **A** 借结构，表面保持我们的纸色和实拍的光。最像一支成熟的产品团队，辨识度靠照片。
- **B** 几乎不借表面，结构也按展厅来。最像我们自己，也最冒险：容易被读成美术馆而不是工作台。
- **C** 借了结构，也借了戏剧性的表面。第一眼最惊艳，离安静最远。

## 8. 推荐：A 台面

1. **一眼看懂**：窗口完整、居中、最大，周围只有光，没有别的东西和它抢（B 的窗要和墙、展签、画分注意力；C 的窗要和满屏照片分）。
2. **顶尖团队的感觉**：「窗口放在一块有底的圆角面上」和负责人 10-30 提到的 Cursor、Granola、Dia 是同一路，是成熟产品官网的做法；配上我们自己的纸色、细字和一组安静的光影照片，成熟又不模板。
3. **和负责人说过的话对得上**：10-30「产品窗口要放在一块有内容的底上，软的照片对硬的界面才有质感」，同一天「照片铺满一屏当背景更吵、更丑」——台面正好是「有底，但不铺满」。
4. **好铺到全站**：首页舞台、Tool 的屏幕、企业合作的书架、社区的作品都已经是「一块面上放一样东西」，换成台面改动最小；DESIGN.md 只新增一个容器。

如果更看重辨识度、愿意承担「像美术馆」的风险，选 B；C 不建议，除非想要强烈的戏剧性。
