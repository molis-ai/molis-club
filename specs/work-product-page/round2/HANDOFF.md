## 8. 坑和经验

- **Issue**：0.3.0 的内置插件里有它；画底栏、插件切换器、⌘K、右侧栏时都要避开。
- **样式会串**：站内跳转后，之前页面的 CSS 还在。Work 页时间条用了 `.wd`，所以下载页改用 `wdl-` 前缀。新写的类名先搜一下有没有重名。
- **Jost 的连字符很宽**：真实命令里 `--` 会挨成一道长横；`code.css` 关了连字和字偶、拉开字距。
- **首屏画面在 901–1240 宽会裁切**：画面里的字有底字号，不随宽度再缩；已按宽度分段改比例，用 `heroclip.mjs` 量过 360–1441。
- **Reel 的比例写在行内样式**，覆盖要 `!important`；读者切换靠 `[data-p]` 加 `display: none !important`。
- **oxlint 的 no-thenable**：对象里不能有叫 `then` 的键。
- **测试会找的字**：`/work` 要有「你主要做什么」「已发布 · v0.2.0」「开发中」「界面示意」、仓库链接和 `#run-from-source`；不能有「下载 Molis / 安装包下载 / 立即下载」和「Issue」。拿掉现状段时，「已发布 · v0.2.0」要在别处还有（首屏写代码版的标签里有）。
- **原句核对**：`content/site/*.ts` 里标「原句」的要和 `docs/studio-intro.md` 一字不差，测试会查。
- **命令行**：zsh 里 `gh api 'repos/...?...'` 要加引号；不要用不带名字的 `git stash`（别的会话共用）。
- **首屏循环截图**：时间点要算好，`WAIT` 太晚会截到循环重置时的半透明帧，看起来像重叠。
