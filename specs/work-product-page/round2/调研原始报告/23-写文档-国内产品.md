## 1. Feishu / Lark (飞书): 知识问答, aily → 豆包工作伙伴, 多维表格, 妙搭

**1. Problem and audience.** An enterprise suite (chat, docs, meetings, Base) adding agents that work inside the company's own context. Buyers are organisations; the audience is knowledge workers.

**2. How the AI works**
- **2025-07-09 launches** [fetched] [qbitai](https://www.qbitai.com/2025/07/306614.html), [ifanr](https://www.ifanr.com/1630203):
  - **知识问答** answers from chats, docs and meeting minutes the user can already access. It needs no knowledge base built in advance.
  - **aily** is an enterprise agent builder: set a persona, attach company knowledge, connect business systems over MCP.
  - **妙搭** builds business systems from a prompt.
  - **多维表格** gained AI agent nodes in its workflows.
- **Base AI** [search-snippet] [feishu.cn](https://www.feishu.cn/content/article/7588081416752106693): AI field shortcuts (extract, classify, summarise; DeepSeek can be used), AI-written formulas, "AI 指令建表" (build tables by instruction), and an AI Agent node in automations.
- **2026-03-19** [fetched] [qbitai](https://www.qbitai.com/2026/03/389311.html):
  - A personal aily agent that has "the same permissions as the user", plus an aily Pro web UI.
  - "多维表格 AI 搭建" generates tables, dashboards, surveys and permission settings from a description.
  - Feishu open-sourced an **official OpenClaw plugin**. It lets OpenClaw act as the user on docs, Base and calendar. Kimi, Coze, MiniMax and Zhipu have integrated with it.
- **2026-08-14:** aily was renamed **豆包工作伙伴** [fetched] [aily help](https://aily.feishu.cn/hc/1u7kleqg/1cnvbb55).
- **2026-09-15: Feishu 8.0**, "rebuilt for agents" [fetched] [gmw](https://economy.gmw.cn/2026-09/24/content_39019145.htm).
  - You add the agent to a group chat.
  - It writes docs, operates Base, manages calendar and to-dos, joins meetings, reads 妙记 (meeting minutes) and the cloud drive, and starts approvals.
  - So it takes real write actions, not just answers.
- **Select-text (划词) menu in Feishu Docs:** UNVERIFIED.

**3. Where the AI can act**
- Across Feishu apps, plus "skills and connectors" into business systems [fetched, gmw].
- **MCP:**
  - Official `lark-openapi-mcp` is still **Beta**. It runs locally via npx, uses tenant or user tokens, and supports docs only for import and read. It has 840 stars [fetched] [GitHub](https://github.com/larksuite/lark-openapi-mcp).
  - aily itself can connect to MCP servers [fetched, qbitai 2025].
- **Permission model is contradictory across sources:**
  - "Same permissions as the user" [fetched, gmw; qbitai 2026-03].
  - "The agent has its own identity, permissions and memory" [fetched] [QQ/潮新闻](https://news.qq.com/rain/a/20260915A07IOR00).
- Admins can trace usage and cap AI spend [fetched, gmw].

**4. Outputs and sources.** Outputs are real Feishu docs, Base tables and calendar events. Feishu's own guide asks users to trace answers back to specific passages. That reads more like an evaluation habit than a guaranteed citation UI [fetched] [feishu.cn](https://www.feishu.cn/content/article/7667878414023396328).

**5. Memory and models**
- The agent "有记忆" (has memory), but the mechanism is undocumented [fetched, aily help].
- Model menu [fetched, aily help]:
  - Doubao Seed 2.x
  - Kimi K3 / K2.6
  - MiniMax M3
  - GLM 5.x
  - DeepSeek V4 / V3.2
- Custom models connect via API from Volcano Engine, Alibaba Cloud or Tencent Cloud, but only on higher tiers since 2026-06-01.
- On-premises and overseas models are not supported. Web access covers mainland China only and does not reach intranets.

**6. Extensibility for non-coders.** Strong: aily/豆包工作伙伴 skills, Base automations, 妙搭, AI-built Base apps.

**7. Local vs cloud.** Cloud SaaS. On-premises models are explicitly not supported for this product [fetched].

**8. Pricing** [fetched, aily help]
- Personal: 豆包订阅 at ¥68 / ¥200 / ¥500 per month; 飞书 AI 会员 at ¥69 per month.
- Enterprise: AI 基础版 at ¥9,900 per year for 180k points.
- Charged per output: a doc costs 2 points, a PPT 10.
- "主动工作" (proactive work) has been billed since 2026-09-01 at 20 points per workday.
- 豆包工作伙伴 is still in co-creation with selected enterprises [fetched but garbled page] [cnr](https://tech.cnr.cn/techph/20260915/t20260915_527814511.shtml).

**9. Complaints**
- Points-based "时间+用量" billing is opaque, and the paid tier is not clearly more accurate [search-snippet] [bilibili](https://www.bilibili.com/read/cv51142017).
- Feishu itself blames inaccurate answers on stale materials and permission mismatches [fetched].

**10. Comparison with Molis Work**
- **Closest overlap:** an assistant that writes into docs, tables, tasks and calendar under user permissions.
- **Clearly ahead:** team agents in group chats, the Base and automation depth, admin governance, distribution.

## Market evidence: how Chinese knowledge workers use AI

- **Multi-app switching is the norm** [fetched] [QuestMobile 2026-10-13](https://www.questmobile.com.cn/research/report/2109848735332814849):
  - 5.37亿 (537M) AI-app users in August 2026, 85.1 uses per month each (+67.1% YoY).
  - Users switch tools by scenario. There is **no "超级入口"** (super entry point) covering every scenario.
  - **Nearly 20% of deep users run 5 or more AI apps.**
- **Office AI is moving to desktop clients** [fetched] [QuestMobile 2026-09-01](https://www.questmobile.com.cn/research/report/2094686886299705346):
  - PC-client AI office usage grew +340.6% YoY, versus +261.1% for apps.
  - The office-agent field is "三强" (three leaders): Tencent, Douyin (ByteDance) and Alibaba.
- **Chat that never lands in documents is a stated pain, but stated by vendors, not by independent surveys:**
  - Tencent Docs pitches an end to "来回切屏、手动复制粘贴" (switching screens back and forth, manual copy-paste) [search-snippet] [CSDN](https://www.csdn.net/article/2026-06-06/161742040).
  - WPS's 田然: most AI office products "stay at dialogue level" [fetched, Sina].
  - I found no independent survey quantifying copy-paste pain.
- **Data and security concerns are explicit:**
  - The OpenClaw ("龙虾") agent craze brought data leaks, permission overreach, remote hijacking and plugin poisoning [fetched, Yicai].
  - Enterprise worry is summed up as "权限管不住、操作查不到、成本算不清" (can't control permissions, can't trace actions, can't account for cost) [fetched, qbitai 388845].
  - The Doubao AI phone backlash, and WorkBuddy's "no scanning" file policy, both reflect privacy sensitivity.
- **Obsidian and local-first:** active among enthusiasts but niche.
  - The 少数派 (sspai) Obsidian tag lists 19 articles, including "官方「数据库」上线，Obsidian 可以替代 Notion 了吗？" (2025-08-21) [fetched] [sspai](https://sspai.com/tag/Obsidian).
  - The Obsidian Chinese forum has around 10.2k topics [fetched] [forum](https://forum-zh.obsidian.md/).

  - No adoption numbers found.

## Patterns across the Chinese market

1. **Write actions are now table stakes.** Feishu 8.0, 悟空, 灵犀专业版, 豆包工作 and WorkBuddy all create docs, tables, events or approvals, usually under the user's inherited permissions with admin audit and caps.
2. **The desktop "龙虾" (OpenClaw-style) agent wave is Molis's real competition.** WorkBuddy (6.58M MAU), QClaw, TRAE Work, 豆包工作 and 悟空 all offer local files, skills, MCP, IM remote control and approval gates. Their distribution dwarfs any independent tool.
3. **"Skills" is the vocabulary non-coders hear; MCP stays developer-facing.**
   - Feishu's and DingTalk's MCP servers are beta or app-credential, local npx tools.
   - Notable exceptions: WPS 笔记 (cloud, local and CLI MCP), Metaso, and Quark's command-line hooks.
4. **Multi-model menus are standard** (Feishu lists five vendors; WorkBuddy four; ima offers Hunyuan, DeepSeek and an API key). BYO model is mostly enterprise-only or limited to higher tiers. **No major player is local-first or local-model.** Feishu explicitly does not support on-premises models.
5. **Billing has shifted to points and tokens, with backlash.** WPS "套娃收费", the opacity of Feishu's points, DingTalk's outcome-based pricing idea. A simple BYO-key model is a credible differentiator.
6. **Regulation shapes features.** The July 2026 rules on anthropomorphic AI killed character agents and pushed vendors toward "工具型智能体" (tool-type agents).

**Implication for Molis Work.** Its open-source, local-first stack with per-action undo cards is unoccupied among the major players. But it has to interoperate with Feishu, DingTalk, WPS and WeCom, where Chinese work actually lives. And it competes on feature parity with free, heavily distributed desktop agents.
