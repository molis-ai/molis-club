## 1. Microsoft 365 Copilot

**Problem / audience.** Built for enterprise knowledge workers already on M365. The assistant is grounded in their mail, files, meetings and chats ("Work IQ").

**How the AI works**
- **Select-text menu in Word.** Select text, pick Copilot from the mini toolbar, then choose Auto Rewrite or describe a change. Results can be Replaced, Inserted below or Regenerated. https://support.microsoft.com/en-US/Word/edit-with-copilot-in-word [fetched]
- **Agent Mode ("Edit with Copilot").** Copilot edits in place in Word, Excel and PowerPoint. It became the default experience for M365 Copilot and Premium subscribers on Apr 22, 2026. https://www.computerworld.com/article/4163305/agent-mode-is-now-available-in-microsoft-word-excel-and-powerpoint.html [fetched]
  - Microsoft's roadmap says changes are "fully reviewable and reversible". https://mc.merill.net/message/RM557673 [search-snippet]
- **Copilot Cowork.** Generally available Jun 16, 2026. It runs long, multi-tool tasks across Outlook, Teams, Word, Excel, PowerPoint and OneDrive. https://microsoft.com/en-us/microsoft-365/blog/2026/06/16/copilot-cowork-is-now-generally-available [fetched]
  - It can edit existing Office files while keeping their OneDrive/SharePoint version history.
  - It can use local Edge browsing with your sign-ins (GA Aug 2026).
  - It has event-driven tasks and an App skill that builds no-code apps (Frontier preview).
  - Source: https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/whats-new [fetched]
- **New "Home / Code / Autopilot" (Sep 25, 2026).**
  - Home merges Chat and Cowork into one surface.
  - Code builds apps and automations.
  - Autopilot is a persistent agent with its own identity, memory and computer.
  - Status is mostly Frontier or private preview. https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/ [fetched]

**Where it acts; approval and undo**
- **Approvals in Cowork.** Cowork asks before sensitive actions (send, post, create). You get these options:
  - approve once;
  - "don't ask again" for the rest of the session, which can be scoped to one recipient or domain;
  - "Approve All";
  - Cancel.
- Granted permissions can be reviewed in a side panel.
- File edits ask "Approve once" or "Always allow".
- Event-triggered tasks default to draft-and-approve.
- Source for all of the above: https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork [fetched]
- **Undo.** Undo relies on OneDrive version history, not a per-action undo (same page).
- **MCP.** Federated Copilot Connectors built on MCP became GA on Sep 23, 2026. https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes [fetched]
- **Plugins.** Cowork supports MCP apps and plugins (Jira, Salesforce, SAP and others). [fetched, whats-new page]

**Outputs and citations.** Outputs are real Office files in an output folder and the OneDrive "Cowork" folder, or edits saved to the original file. [fetched, use-cowork page]

**Context, memory and models**
- **Memory.** Saved memories are managed under Settings > Personalization. https://support.microsoft.com/en-US/Microsoft-365-Copilot/manage-copilot-memory-in-microsoft-365-copilot [search-snippet]
- **Model choice in Cowork.** The picker defaults to Auto and also offers GPT 5.5, 5.6 Sol/Terra, GPT 6 Astra, Opus 5, Sonnet 5 and Fable 5.1.
  - Each response carries a model badge.
  - Admins can only switch the whole Anthropic family off, tenant-wide.
  - Source: https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models [fetched]
- **Model choice elsewhere.**
  - "Switch Model" regenerate in Copilot Chat (Oct 6, 2026).
  - Model choice in Researcher (Aug 25, 2026).
  - Sonnet 5 is the default for higher-reasoning tasks in Word (Aug 25, 2026).
  - Source: release notes above [fetched]
  - Taken together, switching models inside one conversation with the context kept looks supported. That is my inference from the per-response badges and the "Switch Model" feature, not a documented statement.
- **No bring-your-own key or local model.**

**Extensibility for non-coders**
- Skills can be made with a guided builder, by asking in chat, or by dropping a SKILL.md file in OneDrive (up to 50).
- Cowork imports Claude-format plugin packages.
- Skills are scored and gated automatically before they ship.
- Source: use-cowork and whats-new pages [fetched]

**Data handling**
- Everything is cloud. Microsoft says Cowork "operates within your Microsoft 365 trust boundary" and that files are not stored locally. DLP is listed as "coming soon". [fetched, GA blog]
- Anthropic and OpenAI models run as subprocessors. Fable requires the model provider to retain prompts and responses. [fetched, cowork-models and whats-new pages]

**Pricing / status**
- Cowork needs the M365 Copilot license plus usage billing in Copilot Credits ($0.01 per credit pay-as-you-go). [fetched, GA blog]
- Cowork, Code, Autopilot and frontier models move to usage-based billing. [fetched, Sep 25 blog]
- List prices: about $30 per user/month for enterprise and $21 for Copilot Business. https://eesel.ai/blog/copilot-pricing [search-snippet]
- E7 at $99 per user from May 1, 2026. https://www.geekwire.com/2026/microsofts-new-copilot-cowork-integrates-anthropics-claude-in-rollout-of-new-e7-licensing-tier/ [search-snippet]

**Complaints**
- Recon Analytics (150k+ US respondents): Copilot's share as people's first-choice AI fell from 18.8% to 11.5% between Jul 2025 and Jan 2026. Some firms use about 10% of the seats they bought. Users complained about confusing branding and poor cross-app behaviour, and the report praised Claude Cowork for working across 365 apps. https://gigazine.net/gsc_news/en/20260205-microsoft-copilot-problem [fetched]
- Bloomberg reported Amgen staff preferring ChatGPT despite a 20k-seat Copilot purchase. https://www.tomsguide.com/ai/microsoft-reportedly-struggling-to-convince-companies-to-buy-copilot-yup-employees-prefer-chatgpt [search-snippet; I could only fetch the headline]
- Microsoft removed "unnecessary Copilot entry points" from Windows apps after user feedback (Mar 2026). https://en.wikipedia.org/wiki/Microsoft_365_Copilot [fetched]

**Closest overlap with Molis Work:** Edit with Copilot plus Cowork is the same pattern of an assistant that calls app actions behind per-action approval cards, with Claude and GPT in one picker.

**Clearly ahead of a pre-release local app:**
- native Office editing that keeps version history;
- enterprise grounding across Work IQ;
- event triggers and a plugin store;
- mobile apps;
- governance and billing controls.

## 2. Google Workspace with Gemini

**Problem / audience.** Built for Workspace teams. The assistant lives in a side panel in every Google app.

**How the AI works**
- **Unified side panel.** From Sep 2, 2026 the side panels in Gmail, Drive, Docs, Slides and Chat share one feature set. From Docs, Gemini can send an email, schedule meetings, log Google Tasks, and create Docs, Sheets or Slides (for example, turning a proposal into a deck). https://9to5google.com/2026/09/09/gemini-workspace-side-panel-upgrade/ [fetched]
  - The article does not say whether Gemini confirms before sending.
- **Gemini "tasks" agent.** Previously called Spark, now Task.
  - It acts in Gmail, Calendar, Docs, Sheets, Drive, Keep and Tasks, and can use your local Chrome.
  - It asks for review before sending, modifying data, buying or submitting forms. Bulk actions on private Google Tasks are the exception.
  - It runs up to 15 tasks at once.
  - Eligibility is narrow: personal accounts only, Google AI Pro or Ultra, and not available in the EEA, UK, Switzerland or Nigeria.
  - Source: https://support.google.com/gemini/answer/16596215?hl=en [fetched]
- **Workspace Studio** (formerly Flows). A no-code tool where Gemini builds workflows. It connects to Gmail, Chat, Drive, Sheets, Asana, Jira and Salesforce. Workflows only access what the user who starts them can access. https://workspace.google.com/studio/ [fetched]
  - It went GA in Dec 2025. https://www.thurrott.com/google/330391/google-workplace-studio-is-now-available [search-snippet]

**Where it acts.** Across Google apps; third-party apps only through Studio connectors.
- Google's Workspace MCP server reached public developer preview on May 1, 2026. https://workspaceupdates.googleblog.com/2026/05/agent-tools-and-security-updates-for-workspace-developers.html [search-snippet]

**Outputs and citations.** Outputs are real Docs, Sheets and Slides saved to Drive, plus Tasks and calendar events. [fetched, 9to5google] Deep research cites sources. [search-snippet, same coverage]

**Context, memory and models**
- Gemini models only.
- Past-chat memory is not available on work or school accounts or in the EEA, UK or Switzerland. Memory import from other assistants arrived in Mar 2026. https://9to5google.com/2026/06/18/gemini-live-memory [search-snippet]
- No bring-your-own key.

**Extensibility.** Gems are being replaced by "skills".
- Skills in the Gemini app started rolling out Oct 13, 2026.
- Skills inside Workspace (including Studio) are delayed "until further notice."
- Source: http://workspaceupdates.googleblog.com/2026/10/an-update-on-launch-of-skills-in-gemini-app-and-workspace.html [fetched]

**Data handling.** Cloud only. Studio respects Workspace DLP, but DLP for third-party services is "not in near-term plans." [fetched, Studio page]

**Pricing / status**
- The pricing page served me yen prices. Gemini in Docs, Sheets and Slides is not included in Starter. Workspace Studio and "Gemini Notebook" are on all plans. https://workspace.google.com/intl/en/pricing.html [fetched; I could not get USD prices]
- AI Pro is $19.99/month and AI Ultra $99.99/month. One source still cites $249.99 for Ultra, so this conflicts. https://www.igeeksblog.com/what-is-gemini-spark/ [search-snippet]

**Complaints**
- A two-week hands-on test (Aug 18, 2026) found:
  - three-topic thread summaries dropped one topic;
  - drafts were generic when the account had little context;
  - Calendar could not manage attendees;
  - per-user limits returned after Jul 15, 2026;
  - the side panel silently disappears when "smart features" are off.
  - Source: https://geeks.it.com/?p=1049 [fetched]
- The tasks agent is unavailable on work accounts. [fetched, Gemini help page]
- Skills in Workspace are delayed. [fetched, Workspace Updates post]

**Closest overlap with Molis Work:** the side-panel assistant that acts across mail, docs, calendar and tasks, and turns a document into a deck.

**Clearly ahead of a pre-release local app:** deep Gmail and Drive integration, real-time co-editing, scale, and NotebookLM.

## 3. Claude (Claude.ai, Desktop, Cowork, add-ins)

**Problem / audience.** Started with power users and is now aimed at general knowledge workers. Cowork was explicitly a non-coding agent.

**How the AI works**
- **Cowork timeline.** Research preview Jan 12, 2026 → GA on macOS and Windows desktop Apr 9 → web and mobile Jul 7 → Sep 16: "everything Claude Cowork does available from any conversation," with no mode to pick. https://support.claude.com/en/articles/12138966-release-notes [fetched]
- **Office and Google add-ins.**
  - Claude for Excel and PowerPoint (Feb 5); the two add-ins share context (Mar 11). [fetched, release notes]
  - Google Docs, Sheets and Slides add-on in beta (Oct 6, 2026). It sees the open file and your selection and edits inside the file. https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides [fetched]
- **Claude Docs and Slides.** Living documents and decks, available on every plan (Sep 16). [fetched, release notes]

**Where it acts; approval and undo**
- **Approval modes in Cowork.** "Automatically approve" (screened), "Manually approve" or "Skip all approvals".
  - Claude always asks before permanently deleting files.
  - Computer use asks per app but has no sandbox.
  - There is no undo; Anthropic recommends backups.
  - Source: https://support.claude.com/en/articles/13364135-use-claude-cowork-safely [fetched]
- **Google add-on.** Defaults to "Ask before edits" approval cards, with suggestion cards for large rewrites. [fetched]
- **Microsoft 365 connector.** Gained write tools (draft, send, organise email) on Jul 7, 2026; Teams stays read-only. [fetched, release notes]
- **Local MCP.** Local MCP servers run only in local sessions; admins can disable them and desktop extensions via MDM. https://support.claude.com/en/articles/14479288-claude-cowork-architecture-overview [fetched]

**Outputs and citations.** Outputs are editable files next to the conversation, or in-place edits in Docs, Sheets and Slides. Chat search cites the past chats it draws on. [fetched]

**Context, memory and models**
- Memory is on by default for Free, Pro and Max and off for Team and Enterprise.
- Each project has its own memory.
- Local Cowork sessions don't use memory.
- Memory import and export is experimental.
- Source: https://support.claude.com/en/articles/11817273-using-claude-s-chat-search-and-memory-to-build-on-previous-context [fetched]
- Claude models only. Enterprise add-ins can route through an LLM gateway (Bedrock, Vertex, Foundry) as of Mar 11. [fetched]

**Extensibility.** Skills, connectors, a plugin marketplace (Feb 24) and a plugin developer portal (Sep 25). [fetched, release notes]

**Data handling**
- Cloud sandbox by default. Even local files are processed on Anthropic's servers. [fetched, architecture page]
- Team and Enterprise conversation data is not used for training. [fetched]

**Pricing / status** (https://claude.com/pricing [fetched])

| Plan | Price |
|---|---|
| Free | $0 |
| Pro | $20/month |
| Max | from $100/month |
| Team | $25 or $125 per seat |
| Enterprise | $20 per seat + usage |

Usage limits reset on a rolling 5-hour window, plus weekly caps.

**Complaints**
- Cowork reportedly deleted a user's family photos (Feb 2026); they were restored from iCloud. https://en.wikipedia.org/wiki/Claude_(language_model) [fetched]
- Claude in Chrome still fell to prompt injection 11.2% of the time after mitigations. [fetched, same page]
- Fable 5 access was suspended Jun 12 to Jul 1, 2026. [fetched, release notes]
- Status conflict: Wikipedia says Claude in Chrome went GA in Aug 2026, but the release notes only show "beta to all paid plans" (Dec 18, 2025).

**Closest overlap with Molis Work:** this is the closest overall — local folders plus desktop app, docs with suggestion and approval cards, selection-aware add-ins, skills and plugins, and MCP.

**Clearly ahead of a pre-release local app:** frontier models, Office and Google in-file add-ins, cloud execution that keeps running with the laptop closed, and a plugin ecosystem.

## Evidence on multi-assistant use and model switching

**People use several assistants**
- Menlo 2026 (Sep 16, 2026; 5,067 US adults): https://menlovc.com/perspective/2026-the-state-of-consumer-ai/ [fetched]
  - average of 3.0 general assistants per AI user, up from 2.2 in 2025;
  - ChatGPT 60%, Gemini 58%, Claude 20% of AI users;
  - consumers use a "rotation" of assistants.
- Menlo 2025: 91% reach for their favourite tool for nearly every job. https://menlovc.com/perspective/2025-the-state-of-consumer-ai/ [fetched]
- a16z (Mar 9, 2026; Similarweb data): about 20% of weekly ChatGPT web users also used Gemini that week. https://a16z.com/100-gen-ai-apps-6/ [fetched]
- Microsoft Work Trend Index 2024: 78% of AI users bring their own AI to work. https://www.microsoft.com/en-us/worklab/work-trend-index/ai-at-work-is-here-now-comes-the-hard-part [fetched]

**Switching models mid-task.** I found no quantitative data on how often non-technical users do this. The only signals are product changes (M365 "Switch Model", per-response model badges) and forum complaints when the ability was removed.

**Copy-paste between chat and documents is a pain**
- The NBER "How People Use ChatGPT" paper (Sep 2025): Writing is 40% of work messages, and about two-thirds of Writing messages ask ChatGPT to modify text the user supplied. Indirectly, that text has to be brought into the chat. https://www.nber.org/papers/w34255 [fetched PDF]
- Cowork shipped "improved paste handling" for content pasted from Teams, Outlook and browsers. [fetched, whats-new page]
- A tester concluded Gemini "is only as good as the context it can reach." [fetched, geeks.it.com]
- Anthropic's Economic Index names access to context as a bottleneck. https://www.anthropic.com/research/anthropic-economic-index-september-2025-report [fetched]
- Every vendor shipped in-document add-ins in 2026, which suggests they see the same pain (my inference).
- I found no survey that measures copy-paste pain directly; the LayerX data I looked for could not be fetched.

## Cross-product patterns

1. **Everyone is converging on the same shape.** Chat and agent are merging into one surface (Claude Sep 16, Microsoft Home Sep 25). "Pages/Docs" artifacts are shipping (Copilot Pages, ChatGPT Pages, Claude Docs). Skills are replacing GPTs and Gems, and SKILL.md is becoming a format that works across vendors.
