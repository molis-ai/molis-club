## 页面

1. **首屏 · 周一早上**（样稿 B）：上面是字——左边标签行（工作台 · 开发中）、产品名、开场句、英文口号，右边一句「是什么」和「报名首批试用」；下面一整块 2 : 1 的舞台：一面有叶影的墙、木桌、绿植（`work-stage`，原图 1440 宽），项目首页的窗口落定在上面（只报变化：昨晚到今早发布前检查台、助理、Codex 各做了一件，等你的两件，「你」停在「等你验收」上）；窗外左上是菜单栏胶囊「划线卡片 · 2 件等你」，左边压住窗口的是你自己终端里的 Codex（经 MCP 读同一份目标，修好 #12 交回 Molis Work）。窗外两样不进编排，样式按窗口里已出现的事件一行行亮起；入场是照片淡入、窗口落定、窗外两样最后浮出。窄屏舞台竖一点，终端压在窗口左下；手机上只留窗口和胶囊。
2. **全景 · 一个项目，一张工作台**：一整扇窗（照 Soft Workbench：珍珠灰桌面、白色工作面、标签按插件着色、底栏插件组 / 助理输入框 / 右栏开关），里面是一个正在推进的项目：Pages 里一页「v1.1 发布说明」（挂在目标下、引用 3 份资料、一张改动表带出处和状态、助理整理的已知问题），右栏 Shelf 有材料、网页和各个 AI 交来的生成结果。六段依次走：项目、插件、助理、外部 AI、讨论、等你；画框就是窗口的边，每段镜头推近到那一处（宽屏最多 1.5 倍，窄屏 2.2 倍，窗口始终铺满画框），停稳了光标再动。每段一小段编排（第一段几张标签依次亮一下；按开插件表、停在你做的检查台；选中一句交给助理，它回话、写明参考、出待你确认的操作卡；终端经 MCP 读同一份目标，表里那一行变成 Claude Code 在做；右栏切到讨论，请来测 Android 的两位朋友报问题，助理对上已知问题，你 @Codex，它接下；点开等你的两件，停在「去验收」）。整段一屏放下：上面只有眉题和标题；窗口下面是六段（像章节条，墨线和镜头同一个节奏）、「界面示意」和开关；最后一句是这一段的说明（标题墨色、说明浅一档，连成一句，留两行高）。窗口配色浅色 / 深色可切。
3. **用起来 · 一件事，从开头接到做完**：左边是角色（写代码 / 做内容、运营，记在这台浏览器里）、两条闭环（和团队一起 / 长出自己的工具）和五步，右边一扇窗按时间演；点某一步从那一步演起，可暂停、可从头看。四个 case：
   - 写代码 × 和团队一起：从一句抱怨，到修好（Feed 里三条反馈说的是同一件事 → 项目记忆里的复盘 → 你的 Codex、阿哲的 Claude Code 各接一件，拿不准的两笔你定 → 真机上付一笔才算修好 → 回信给门店）
   - 写代码 × 长出自己的工具：从一句闲聊，到一个插件（「模拟用户」：助理接住愿望带着方案来 → 创作台里搭出来 → 三个人同时去试 → 交给 AI 修，再试一遍）
   - 做内容、运营 × 和团队一起：从一条热点，到发出去（Feed 里的热点 → 账号定位与上回的复盘 → 你的 Claude 写底稿、小林的 ChatGPT 做小红书 → 你点过头才发 → 第二天读者的问题回到 Feed）
   - 做内容、运营 × 长出自己的工具：从一句闲聊，到一个插件（「每日选题」：每个题写清给谁看、为什么现在写、依据在哪；不对就说，改了规则重出）
4. **为什么是 Molis · AI 很多，工作只有一份。**：讲完产品和用法以后说清差异。页面上托着一块深色的展台（四周留一圈纸色、圆角，滚进来时从略小放到位，顶栏仍压在纸色上）。左边字小一号：标题、一句导语、四条（要点 + 一句话，点亮的那条多一行；左边一根细竖线，杏色走完换下一条，鼠标停上去就停住），最后两句「问一句就走的事，聊天就够了。要接着做下去的，交给 Molis。」。右边一份工作记录在中间（后面叠两张旧版），左边 Claude Code、Codex、OpenCode，右边你、助理、同事，都是 App 图标式的方块。每条演一个小故事，先是通常会怎样，再是在 Molis 里怎样：接得上（Claude Code 额度用完熄掉，Codex 接上，气泡「读到了你周六定的事」，表里换成 Codex 接着做）；对得上（Codex 报「做完了 · 测试 16/16」，记录上亮出「收尾未生效」，等你验收在闪，轮到你）；长出来（记录上方一个虚线框长成你做的发布前检查台，连上记录，Claude Code 也连过去调它）；是你的（一圈「你的电脑」框住记录，下面模型从 Anthropic 换到通义千问再到 DeepSeek，记录不动）。studio-intro 原句「工作数据保存在本机，使用 AI 时会调用你配置的模型服务。」在「是你的」那条里。窄屏不画连线和气泡：上面三个外部 AI、记录、下面你、助理、同事。
5. **缘起与现在 · 等你决定**：上字下窗，和首屏一样：「一开始，我们只是想做一个让自己团队用得更顺的工具。」→「判断归人，执行可以托付。」（原句）与它的解释；下面一扇开窗的照片（`work-close`：首屏同一组里坐着读书的人），墙上浮着一张照 Molis Work「决定请求」画的卡，三个选项就是三个去处：报名首批试用、从源码构建（开发中）、看源码（已发布 · v0.2.0）；卡浮上来以后「你」的指针移到主选项。1100 宽以下卡挪到照片下面压住下沿。
