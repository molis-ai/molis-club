# 工作室首页与配套插画

## 背景与目标
用户否定了空间圆环首页，要求恢复原围桌插画，首页呈现简约、高级、宁静的设计师工作室质感，并绘制同系列内页插画。最新明确要求：网站不出现“移动鼠标，轻点空白处”等操作说明。本规格替代之前圆环方案；历史实现留在 Git 中。
完成等级：功能可用，发布到现有私有 Sites 站点。

## 当前问题与证据
之前首页包含重复口号、多个入口和背景操作说明，用户认为过乱。空间圆环被用户明确拒绝。以原 public/images/molis-makers-studio.png 作为视觉依据，不重新选择艺术方向。

## 范围与非目标
保留 Molis AI 品牌、原 Logo、原围桌插画、暖纸/墨蓝、Geist/Newsreader、五项导航和全部真实内容。首页不恢复产品、方案、观点、FAQ 等纵向模块。不修改数据库、账号、产品事实与站点访问范围。
新增三张配套插画，只用于百科现有收尾、观点现有封面、方案介绍。原画不改像素；新插画不冒充真实合影或产品截图。

## 场景、方案与关键决策
THESIS：一个安静的工作室入口，由原插画与清楚的文字建立身份。
OWN-WORLD：暖纸、墨蓝、细密铅笔线、低饱和水彩、真实纸纹与衬线短句。
STORY：知道是谁、做什么，通过一个作品入口或栏目导航继续探索。
FIRST VIEWPORT：桌面标题在左、介绍和作品入口在右、插画在下；手机按文字、入口、插画自然排列。
FORM：用户直接指定恢复原画与减法，保留原视觉方向；不举行新的概念抽签或构图投票。
FINISH：独立视觉审阅后同步 DESIGN.md，生成资产保留完整提示与来源。

- 唯一主标题为“A curious mind. / A human touch.”；中文介绍为“Molis AI，一间与 AI 一起创作的工作室。做产品，也分享创作的方法。”；唯一主入口“探索作品”到 /products。
- 鼠标产生至多横向7px/纵向4px的插画视差与淡光，离开归位；点击非交互空白产生1800ms波纹，重复点击覆盖上一波。
- 无持续自动动画；无操作说明、暂停按钮、静态画面标签。减少动态偏好直接关闭视觉反馈。交互不拦截滚动，不移动按钮点击区域。
- 原生图片声明尺寸；主页优先加载，内页图片按需加载。服务器输出品牌、正文、链接、元数据；保留私有 noindex。
- 百科：参考书、知识卡与整理材料的手，放在“从看见，到做到”旁；观点：窗边阅读，替换第一篇封面并移除封面的重复英文；方案：两人纸模型协作，放在现有开篇介绍下。

## 输入输出、依赖与文件边界
输入：用户纠正、原围桌插画、现有内容。输出：简化首页、三张JPEG、相应内页接入、更新原私有站点。无新增运行依赖。
实现边界：app/community.tsx、studio-scene.tsx、studio-entrance.css、wiki/page.tsx、perspectives/page.tsx、catalog.tsx、editorial.css；资产 public/images/studio-series/，提示文档 docs/STUDIO-ILLUSTRATIONS.md；验证 tests/discovery-http.mjs；产品/设计/README文档。

## 验收标准与验证
- 首页单主标题、短介绍、一个作品入口；原插画可见，无canvas，无操作说明和旧纵向模块。
- 鼠标与空白点击反馈工作，交互目标不触发波纹；减少动态时停止反馈。
- 桌面1440×1000、手机390×844无横向溢出，图像人物主体完整，导航和作品链接可用。
- 三张新图真实加载于约定位置，不增加新内容模块；完整提示与来源可追溯。
- npm run check、npm run lint、npm run build、node tests/discovery-http.mjs 通过；浏览器检查布局、图片与交互。
- 同一私有站点发布成功，访问范围不变。
