# 工作室首页：一个安静、可触碰的入口

## 背景、目标与完成等级
用户认为首页多个内容模块造成迷茫，确认将其收敛为工作室门面，并要求更好的内容设计与随鼠标、悬停、点击反馈的背景。目标为功能可用并更新现有私有站点；首页清楚说明身份，引导探索，互动有质感且不妨碍阅读。

## 保留、替换与范围
保留 Molis AI 品牌、原 Logo、暖纸/墨蓝、Geist/Newsreader、五项主导航、账号与全部内页和真实产品事实。替换首页正文与大页脚为单场景入口、简短介绍、主 CTA 和紧凑页尾。首页移除产品卡片带、方案、关于、观点、FAQ 等纵向模块，这些内容仍可从栏目到达。旧首页的产品展示和动效方案不再约束本轮。不修改内页、账号、数据库、产品阶段、公开范围。

## 场景与方向合同
Mode: Experience。用户进入首先理解“AI 创作工作室”，然后看作品或从导航进入内容。主文案“把一点好奇，做成真实的作品。”；介绍具体说工具、体验与创作方法。一个主按钮探索作品，团队介绍为低权重文字入口。

THESIS: 以一个可触碰的空间纸环承载工作室的好奇心，页面只做身份与探索入口。
OWN-WORLD: 既有暖纸、墨蓝、杏橙与衬线短句；柔和有向光源、哑光曲面，充足留白。
STORY: 知道是谁、做什么，触碰场景得到回应，自然进入作品。
FIRST VIEWPORT: 桌面左侧大号中文标题和简短介绍，右侧约半屏的空间纸环；底部紧凑的操作提示与联系。手机文案在上，纸环在下，导航仍为原生菜单。
FORM: 用户已确认的单场景工作室入口；沿用已建立品牌并直接实施本次指定交互，不重新举行方向投票。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## 行为与状态
- 背景纸环由实时几何渲染，轻缓变化；鼠标位置改变转向/光影，离开后回到中性位置。点击空白处发出有期限的波纹，连续点击覆盖上一波，不累积节点。
- 悬停主入口时圆环略微展开，按钮箭头回应；按钮保持固定可点击区域，不追逐鼠标。
- 触摸采用轻点背景触发波纹，不阻止原生页面滚动；所有内容与导航不依赖背景。
- 明确暂停/继续按钮，暂停时停止持续绘制；减少动态偏好默认静止且不允许系统偏好被无意覆盖。WebGL 不可用时展示静态几何后备图形；不展示空白或错误提示挡住首页。
- 仅在页面可见、场景在视口内时更新，像素比有上限，定帧率减少资源消耗；卸载清理监听与 GPU 资源。
- 正文/链接服务端可读；首页独立 title/description 与 Organization 说明反映工作室身份，私有 noindex 保留。

## 文件、依赖与验证
改 app/community.tsx、app/page.tsx；新增 app/studio-scene.tsx、app/studio-entrance.css；必要时 lib/site.ts 增加首页用身份文案；更新首页相关 PRODUCT.md / DESIGN.md / README.md / AGENTS.md 和本 spec。不增加第三方依赖，不修改旧全局 CSS 避免影响内页。旧未引用组件暂不做无关清理。

验收：身份清楚、单场景无原有纵向模块；产品/团队/导航/联系可达；鼠标移动、离开、悬停、点击、暂停/继续、减少动态和静态后备可验证；桌面1440/窄屏与手机390无遮挡溢出；同站内页保持。运行 check/lint/build、定向首页 HTTP 契约和已有发现验证，浏览器批量视觉/行为检查。最后按 Impeccable 做独立 finish review 与文档同步，发布沿用 Sites 私有流程。

## 假设与开放项
用户已确认工作室身份与单入口方向。本轮圆环为品牌抽象几何，不冒充作品截图、真实实体或团队照片。没有实测访客转化数据，不宣称已证明首页更易理解。真实手机触摸硬件验证视工具能力报告。

- 通过：暂停后实际 drawArrays 调用数264保持不变，恢复后继续绘制；减少动态时 uTime=0、pointer=[0,0]，绘制数2005保持不变，点击无波纹。

- 通过：npm run check、npm run lint、npm run build、node tests/discovery-http.mjs；没有改动认证、数据库、内页业务行为，不重复全量账号写入测试。

完成等级：功能可用，适用现有私有试用。不存在已知未完成的首页范围项；公开访问与实际收录仍保持原边界。
