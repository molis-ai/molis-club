# 内页滚动叙事重设计

## 背景与纠偏
用户明确不满意上一版，要求不拘泥现状，参考 https://synvas.ai/ 的滚动视觉效果，做更温和有趣、符合 Molis 风格的动效；首页没有问题，保持不变。已在浏览器实际观察参考的素材环绕→散开→画布→结束过渡，借鉴连续叙事，不复制环形、网格或3D飞行。

## 保留 / 替换 / 忽略
保留：首页全部代码与已确定风格、品牌、真实产品事实、外链、筛选、认证与反馈。替换：内页静态英雄区和详情排版，以滚动驱动的物件编排组织内容。忽略：上一轮静态内页的排版约束及其视觉通过结论。

## 范围与完成等级
功能可用的 /products、/solutions、13个 /works/[slug] 滚动体验；先交可交互 Products 切片，再完成方案及详情。原有可用性不降低。文章、登录、首页不在范围内。

## 动效合同
Products：作品桌。六张真实产品签从松散的位置与轻微角度，随滚动连续归拢到「感受 / 日常 / 创造」三组。标题、组名与卡片是一个连续场景；滚动反向可回到前态。无计时播放、无整页滚动劫持，直接跳过入口始终可用。其后是全部真实作品与原筛选。
Solutions：工作连接起来。切换真实方案后，滚动让三个原本错开的业务环节对齐、连接线接通，展示真实阶段边界；示意路径明确标记，不把规划当完成。下方三项详细内容正常可读。
详情：创作手记。作品身份在桌面页边停留，为什么做 / 适合谁 / 当前进度以逐页叠放的纸张进入阅读区。滚动叠页表达阅读进程；手机重新组织，反馈始终可达。
运动语气：轻位移、小角度、连续可逆、无弹跳、无高速飞行。暖纸/墨蓝/真实Logo继承首页，不新增视觉主题。只在可见场景的滚动/尺寸变化时更新CSS变量，不引入动画库或恒定渲染循环。

## 数据/文件/边界
content 为唯一产品事实，4个真实Logo/其余名称排版，现有主题插画仅作插画。新增 app/scroll-scenes.tsx、app/scroll-scenes.css，更新 catalog、inner-pages.css、works详情、共享展示组件（按需）。唯一规格本文件，DESIGN记录最终结果。测试只更新涉及的选择器与真实动效验收，不为流程加系统。

## 可达性与降级
普通页面滚动，无 wheel/touch preventDefault。所有内容默认可见、链接可达。prefers-reduced-motion 和 JS 未启用时取消长场景及空间运动，呈现最终有序内容。减少动态偏好切换即时适用。手机不把桌面画布缩成无法阅读的碎片，卡片/正文保持清晰尺寸和触控入口。

## 验收
- 桌面与手机各至少记录滚动初态/中态/终态，位置与角度发生连续且可逆的有意义变化，不能只凭静态图宣称动效完成。
- 产品筛选、作品外链、方案切换、详情反馈仍可达。滚动可直接离开场景，跳过入口有效。
- 无页面横向溢出；缩放/屏幕尺寸变化后布局可读；减少动态没有隐藏内容或长空白。
- 首页源码无diff；无事实、数据、访问范围变化。
- lint/check/build，原有 discovery HTTP 回归；浏览器验证真实滚动进程与减少动态；独立 scoped motion review。
- 同一私有 Sites 更新，发布前先有可操作切片。

## 本轮验证记录
- lint/check/build 与原有 discovery HTTP 回归通过；detector []。首页 page/community/product-showcase/shell/globals 没有 diff。
- CUA 实际滚动及定点截图：Products 桌面1280×900、手机390×844均0→约0.5→约1；桌面反向回到0.498时矩阵相同。手机初态两签遮挡已集中修正，最新三个状态均无卡片内容遮挡。
- Solutions 同尺寸0→0.5→1，连接线clip从100%到50%到0%；小角度环节归齐。Keyboard Space实际切换Evrik，Aether切换保留方案设计/业务代码未启动事实；说明区间距修复后不被卡片盖住。
- 详情桌面1280×720与手机390×844记录起点/叠页；桌面标题停留45px，纸页依次35/57px叠放，手机反馈继续可达。
- 产品直接浏览入口实际跳到collection（视口top70）。减少动态即时取消长场景，场景与内容同高770px，6链接与有序矩阵保留；真正关闭脚本并重新加载同样显示全部产品签与分类入口。测试后脚本与媒体模拟全部恢复。
- 无页面水平溢出（所测尺寸）；未声称实机触控、全浏览器或帧率基准已测。共18张当前截图在忽略的本地review目录。无新生成或修改raster。
- 独立 scoped motion reviewer 结论为 ship：检查范围内无 Blocker/P1/P2；确认连续滚动编排符合本轮合同。该结论不替代用户对风格与趣味性的判断。
