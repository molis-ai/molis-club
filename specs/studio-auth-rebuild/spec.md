## 背景、目标与当前证据
用户否定旧网站的社区招募气质，要求使用 Impeccable 做成艺术感、简洁的设计工作室网站，并基于文章与 adeptify GitHub 仓库整理产品。品牌已明确更名 Molis AI。最新纠正优先：用户提供的闭环 Logo 完全保留，包括原橙色段；此前改 Logo 是理解错误。冷银白/雾蓝页面被反馈过冷，与“让技术，多一点人的温度”相悖。最终页面改暖米白、柔和墨蓝、浅暖灰抽象光影，橙色仅保留原 Logo 点睛。写实艺术、大片杏橙光影、大 Logo 替代背景、冷色 Logo 版本全部弃用。

## 保留、替换与范围
保留真实产品事实、《落地主义》《人的尺度》正文、既有D1留言及联系申请。替换品牌、视觉、导航、内容结构与身份流程。只编辑community网站及根DESIGN/PRODUCT/README/spec，不更改其他仓库、历史档案或GitHub组织名称。
完成等级3：功能可用的私有预览。不是具备邮件服务、公开运营治理和完整OAuth凭据的正式公众站。

## 设计与信息结构
Experience模式：Geist无衬线与Newsreader衬线斜体，克制留白、用户原始Logo、暖米白与浅暖灰抽象PNG；无写实物件、无卡片墙。页头Products / Solutions / Studio / Journal / 登录；移动至少直接可见Products、Solutions、登录。
Products三线10项：情绪与体验（Elsewhere、Seentoo、ASTRALO），轻量工具（niul.ai、DropAgent、Jelly），AI与工程效率（Prologue、Flyleaf、ForkLight、GoalBoard）。Solutions三项：Content Growth、Evrik、Aether。首页产品线索引，/products分类目录、/solutions场景目录、/works/:slug详情。状态依据当前仓库，私有源码不外链。

## 账号与数据行为
邮箱显示名与12–128位密码注册→登录→HttpOnly会话→刷新保留→退出服务端撤销；改密需当前密码，撤销其他会话。尚未验证的邮箱明确标示，暂无验证/找回邮件。
Better Auth官方Drizzle适配器+D1处理密码、会话和OAuth。Google/GitHub只读基本身份，未配置凭据时按钮显示待开放；不根据未经验证的邮箱自动合并账户。凭据只放忽略文件和Sites secrets。
留言必须站内登录，由服务端确定user_id/显示名；跨用户不能复用请求ID，重试不重复，历史访客留言保留区分。联系申请保持私密。追加迁移，不改已部署历史迁移。
Sites外层ChatGPT owner-only门禁保持；本轮更名URL为molis-ai，未扩大访问范围。

community/app：页面、目录、身份UI与API；content：13项事实与产品线；lib：BetterAuth和留言处理器；db/drizzle：现有业务表及user/session/account/verification/rate_limit追加迁移；public/images：用户原始Logo和暖中性光影；AUTH-SETUP/DEPLOYMENT/PRODUCT-LINES：外部接入和成本说明。

1. 全站Molis AI名称，原始Logo橙色不改；页面暖米白、柔和墨蓝与浅暖灰光影，无大片橙色装饰；桌面/390px主导航可用。
2. Products三线10项、Solutions3项归类正确，详情/文章可读，私有项目成熟度与链接诚实。
3. 邮箱注册、重复/错密码拒绝、会话刷新、退出、改密与其他会话撤销真实工作；密码哈希交由库处理。
4. 匿名留言401；服务端署名；重试持久化无重复；跨站/跨账户冒用拒绝。
5. Google/GitHub适配已配置，缺凭据不假装完成。外部OAuth往返、邮件验证/找回为明确缺口。
6. tsc、build、定向测试与真实本地HTTP+D1通过；UI注册/退出实际验证；独立Impeccable审查；同一Sites私有部署成功。
7. 首屏明确 AI 创作工作室与产品/业务两条路径；目录按场景识别，提供已公开产品入口；详情说明适用场景、当前状态、下一步，保留事实边界。
8. 页面有独立标题、摘要、规范地址与分享元数据；首页、目录、作品和文章提供与可见内容一致的结构化数据。分类在服务端按 URL 呈现，通过真实链接切换；关闭 JS 仍可浏览目录与正文。
9. 保留私有 noindex；robots 与 sitemap 不把私有预览误报为已公开。文档说明公开后开关、Search Console、真实场景内容与流量验证，SEO/GEO 不承诺排名或引用。
10. 正文/关键状态字号、输入字号、点击区域和键盘焦点兼顾舒适阅读与移动操作；不引入弹窗催促、假评价或追踪服务。
