# 场景与覆盖

8 个标签，36 步。每个标签是一个独立的小闭环，人物和数字互不依赖。38 项核心功能每一项都有地方露面，但大项下的细项没有全上，最后一列列出了这次没上的。

[打开 demo](https://claude.ai/artifact/AnZmNq7aQqKU9oUtVEfnE6)

## 自动播放

| 情况 | 行为 |
| --- | --- |
| 停在这一屏，5 秒没有点击 | 一个带角色名的光标移到目标按钮上，按下，进入下一步 |
| 一个场景走完 | 光标移到下一个标签，接着走 |
| 点一下、按键或滚动 | 马上停，从这时起再等 5 秒 |
| 滚出这一屏，或切走浏览器标签页 | 不走 |
| 系统要求减少动态效果 | 不自动播放 |
| 走到第 36 步 | 停住，不循环 |

## 要你定

1. 标签名和顺序。「搓工具」「自动跑」「换个 AI」是我起的。
2. 点击后 5 秒恢复自动播放。我是这样做的，也可以点过一次就不再自动走，要你实际感受一下。
3. 正式上站时路线图功能怎么标。项目规定尚未开放的不得伪装可用，demo 现在只有整体标了「界面示意」。
