# x.ai/bot 能借什么

整体形式不搬。它全页约 10 屏，没有钉住段，一扇窗自己放 33 秒，一个聊天就讲完了。Work 要讲的是工作跨着讨论、Coding、报告、PPT 接下去，还要访客自己点，所以钉住加点击不变。

能借的是下面 7 件。前 3 件会改方案，你点头了我再写脚本。

## 它的做法

| 地方 | 我看到的 |
| --- | --- |
| 开场窗 | 976×660，不缩放。聊天 14px，次要信息 12px。标题和窗同屏，打开就自己放，约 33 秒走完一个任务 |
| 窗里 | 左边 7 个会话，我点过的两个都写好了完整对话，立刻切换。右上的电脑图标点了没反应，不是每个按钮都接通 |
| 说明 | 窗里几乎没有旁白，靠灰色事件行和清单说话 |
| 选角色 | 8 个标签，点了换右边画面和一句话；等了约 10 秒不自己换 |
| 手机宽度 | 还是一扇窗，侧栏收成头像，聊天占满 |

## 能借的

|  | 形式 | 放到 Work | 改方案哪里 |
| --- | --- | --- | --- |
| 1 | 窗按真实大小放 | 设计尺寸从约 1100×700 收到 976×660，正文 14px。HTML 的舞台本来就是 970×615 | 「屏」和「最大的风险」 |
| 2 | 开场自己走一小段 | 标题和首页同屏。窗自己走：简报把 41 条理成 3 条，「你」的光标按下第一个按钮，然后第一个框亮起，交给访客。一个字不写就教会了点 | 「不点」加例外：只有开场 |
| 3 | 进度条变角色标签，能往前跳 | 修复、报告、方案、公众号，各带角色头像。研发直接跳修复，老板直接跳方案。不加内容，还缓解 30 次点击太长 | 「进度」从只能跳回去改成前后都能跳 |
| 4 | 事件行和清单代替旁白 | 「已接上支付后台」「已存一版成果」做成窗里的灰色一行；助理干完给清单「✓ 支付后台 → 失败订单 · 12 笔」。多数帧不用贴旁白，只有转折帧留一句 | 写脚本时用 |
| 5 | 全局跟着动 | 中间每一步，Dock 角标、等你的数字、标签的状态环都跟着变，App 看着是活的 | 质感表加一行 |
| 6 | 走完放开逛 | 收尾后框消失，报告、方案、PPT、稿子都能点开看。内容都是 case 里现成的 | 「框」加一个收尾状态 |
| 7 | Computer Use 卡 | 讨论里一张卡，里面一块小屏幕；状态胶囊从「操作中」到「完成」，轮到人时变「你来」。正好接发送键留给人 | 画这一帧时用 |

第 4、5、7 件也记成给 Molis Work 的产品输入。

## 第 1 件换来的字号

| 视口 | 方案里的估算 | 976×660 |
| --- | --- | --- |
| 1440×900 | 15.6px | 14px |
| 1280×720 | 12.3px | 14px |
| 1024×768 | 11.7px | 14px |

小屏不再糊，代价是窗窄了约 11%，里面的条数要减。视口矮于 720 才缩，最低 90%，再矮走窄屏版。屏更大时进页一次算好放大，最多 1.2 倍。

## 手感之后再定

- **露一面功能的去处：** case 里没有自然时机的，case 后单开一屏：一排标签加一块裁切的界面，同一个位置换着看。它用的是四宫格，但 DESIGN.md 写了一屏一个重点、同类内容同一种看法，所以不照搬。只在觉得 case 太长时才开，PPT、Dataset、团队协作降下来也有地方去。
- **窄屏：** 一期还是裁切，但留窗框和收成图标的侧栏，看着仍是 App。每个视图都做窄布局工作量大，放后面。
- **进场：** 标题先清晰，其余从模糊到清晰依次出来。只用在开头，减少动态时关掉。

## 不借

- **钉住之外的主形式：** 不钉住加自动播放，理由见开头。
- **手机壳：** Molis Work 是装在电脑上的工作台，没有手机版就不画。
- **价格、下载、指南、FAQ：** Work 现在是开发中，入口是报名内测。
- **标题下两三行说明：** 比我们的规矩字多。
- **几乎不用阴影：** 它靠 1px 环线和底色分层，窗是平的。我们按已定的三层暖色阴影走。

## 要你定

1. **前 3 件：** 真实大小、开场自己走、进度条往前跳，要不要进方案。定了我就写脚本。
2. **贯穿的形象：** 它那个带眼睛的球从标题一路到头像、到结尾，是页面最好记的东西。Molis Work 已有标志，要不要也贯穿。建议先不做，case 成了再看。
3. **真人影像：** 它放了一段自己团队在用的影片，最能让人信。有真实素材就放在结尾前，没有就不放，不演。
