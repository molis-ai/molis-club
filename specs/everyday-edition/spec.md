# B 版：日常里的创作工作室

## 目标与现状
A 版已完成并发布，源提交 2dbd756210d7fedc4269724965997cc5546a3ee3，私有 Sites 版本16。用户要求完整保留A，完成后再做参考 everyday.io 的独立B版，逐页对比；不局限首页，允许重做功能入口与信息结构。当前 Session Goal 为两套完整可比较的站点。
完成等级：功能可用，完成桌面/手机视觉与关键流程验收，发布同一私有站点。

## 设计合同
THESIS：让自然光、材料和创作场景承担视觉，让内容一次只说一件事。
OWN-WORLD：Molis AI原品牌、墨蓝与纸色、真实产品和知识；摄影加入鼠尾草灰墙、亚麻、木材、窗光，安静而有生活感。
STORY：日常空间 → 做出的作品 → 可带走的知识 → 创作的人和想法。
FIRST VIEWPORT：使用用户授权的 reading-threshold-v2.jpg，文字位于左侧墙面中部，右侧窗帘/椅子完整保留；非居中套版。导航轻，只有一个主要作品入口。
FORM：采用everyday.io实看参考的全幅照片、宽松标题、紧密图组、整段画面与少量文字，以及按内容切换的展示。用自己的素材、品牌、内容重组。
FINISH：先验证首页真实切片，再适配五个栏目与全部详情/账号路径；独立审阅与文档记录。不以首页截图代表整站完成。

## 保留、替换、忽略
保留A所有页面与行为，根路径继续作为A；B位于 /atelier，另建 /compare 比较入口。保留产品真实阶段、百科/Skill真实下载与复制、观点原文、隐私与账户事实。B可以重新组织现有信息、减少重复、调整功能位置与介绍，不必继承A的组件布局。
替换B的开篇、栏目导航节奏、内容分组、图像叙事、详情阅读与表单外围。忽略A曾经的布局/模块数量约束，不复制参考站的品牌文案、产品素材和视频。
不新增站点/数据库，不改变当前私有权限，不虚构已开放功能。

A: /、/community、/wiki、/products、/solutions、/perspectives 及现有详情和账号页。
B: /atelier 对应首页；/atelier/community、wiki、products、solutions、perspectives；同前缀成员、works、wiki条目、wiki/artists与其详情、story、login、join、account、privacy。
B主栏目重新编排。详情复用真实数据与功能，独立版式适配对应内容。B内导航持续留在B，下载/外链/API路径保持真实目标。比较页支持同一内容的A/B入口。旧别名路由兼容A已有行为。

## 模块与输入输出
新增 B 路由入口、摄影首页/栏目页面、共享B页头页尾、图片组与滚动反馈；共享链接组件或明确页面链接映射保证两个版本内浏览一致。既有A默认呈现不变，B样式作用域隔离。照片来自用户授权Elsewhere资产及imagegen新场景，作为氛围图不冒充真实团队/产品实拍。
输入为content/现有事实、参考网站、用户授权照片；输出为两个可对比入口和完整B页面。艺术家Skill本地生成/复制等操作、账号与联系仍消费既有API，不增加凭据和数据契约。

## 图片计划
保留原阅读空间作为首页；新做创作桌面、知识/阅读、共创空间三组同调摄影。原有产品身份图与艺术家作品继续作为相关内容证据。图片声明尺寸、压缩、首图优先其余按需加载，不以超长视频替代摄影。

## 交互与内容原则
自然滚动，图像轻微移动与缩放；重点图组可以点击/键盘切换，手机可直接访问。每一段只有一个视觉主角，正文集中在必要说明与详情。减少动态、无JS、图像加载失败时，标题与链接仍可见。表单/阅读不强加视差。

## 验收
- A现有16类页面保持可达、主交互不变；新B完整覆盖全部类别，不将用户导航带回A。
- B首页真实照片与墙面左中排版，栏目/详情均按内容适配，至少三组新增图。
- Desktop/mobile无横向溢出，图片不遮挡内容，菜单、内容切换、复制、下载、目录、账户和联系入口可用。
- SEO/GEO事实、canonical、结构化内容与私有noindex边界正确；B重复内容保持明确信息身份。
- npm run check、npm run lint、定向HTTP、npm run build；功能逻辑不改不重复写入测试。
- 两个独立入口与比较入口发布到原私有Sites，交付完整页面范围与实际验证缺口。

## 假设
用户授权重组B的功能与信息，不授权删除A；数据事实与真实可用状态仍应准确。无物理手机，仅浏览器响应式与原生操作验证。
