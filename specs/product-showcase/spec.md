# 首页产品卡片与视觉调整

## 当前需求（以用户最新纠正为准）
Products 使用 Logo + 产品名 + 简短介绍的产品卡片，横向切换，同屏看到多张。用户否定纵向导航列表和类似 PPT 的大幅图文播放。去掉分类标签、大插画、自动播放、播放/暂停和演示式计数器。

## 范围与决策
- 十件作品组成一条横向卡片带。桌面约三张完整卡片并露出下一张；手机一张为主并露出下一张。
- 每张卡片有产品标识、产品名、类别、简短真实介绍、当前阶段和详情入口；整张卡片可进入对应产品。
- 优先使用用户项目现有 Logo：niul.ai、Jelly、Elsewhere、GoalBoard；未找到可用 Logo 的产品使用名称字标占位，不伪造官方标志。先展示有现有标志的四件产品，再展示其余作品；不改变产品目录的分类。
- 原生横向滚动/触摸滑动与左右箭头浏览。键盘可访问每张卡片，聚焦时滚入视野；减少动态偏好下箭头直接定位。没有自动播放或停留计时。
- 保留已完成的首屏双入口、方案步骤、故事和文章动效；网页品牌 Molis AI，仓库/目录/npm 包 molis-club。

## 文件边界
app/product-showcase.tsx、app/community.tsx、app/globals.css、public/images/products/。品牌文案和元数据纠正在 app/ 与 lib/site.ts、lib/auth.ts；文档为 PRODUCT.md、DESIGN.md、README.md、AGENTS.md。无新依赖、数据迁移或访问权限变化。

## 验收与完成等级
首页无大幅产品图文轮播、分类导航或播放控件，卡片以 Logo/名称/简介为主；全部十件产品详情可达。1280px约三张同屏，390px露出下一张；箭头、横向滚动与键盘可用，页面整体无横向溢出。npm run lint、npm run check、npm test、npm run build，浏览器验证关键布局与操作。

既有 owner-only 私有试用网站的首页交互完善，不升级为公开运营社区。前两版 Products 技术检查不代表本版体验验收；未把其发布到线上。
