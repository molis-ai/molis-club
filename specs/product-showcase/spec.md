# 首页联动作品展台与模块动效

## 目标与证据
用户明确否定首页浮动产品卡片，要求左右切换、左图右侧滚动播放列表，并完善各模块动效与视觉。现状 app/community.tsx 是三组插画、浮动链接和折叠作品列表。

## 范围与完成等级
完成可内部体验的首页视觉交互；保留品牌、原图、真实作品事实和全部详情路径。不改目录页、账号、数据库或访问权限，不生成虚构产品截图。

## 行为与决策
- 单一展台：左侧大图与分类短句，右侧当前作品内容及可滚动作品列表。三个分类按钮跳到对应首件作品。
- 左右箭头在十件作品间循环；点击列表切换，当前作品与分类图同步，活动项平滑滚入列表视野，不移动整页。
- 每六秒播放下一件；提供播放/暂停，悬停、键盘进入、页面隐藏、离开视口时暂停；用户手动选择或滚动列表后停止自动播放，显式播放恢复。减少动态偏好下默认停止自动播放和空间位移。
- 手机上下布局，保留全部控件、作品和阅读路径。JS 未运行时首个作品与全部产品入口可见。
- 动效焦点是展台的图文切换和列表定位。首屏文字展开，方案步骤依次进入，关于段落与文章采用轻量局部反馈；不锁滚动，不把正文初始隐藏。

## 文件与依赖
app/product-showcase.tsx 管联动与播放；app/community.tsx 接入及首页；app/globals.css 管样式和渐进增强动效；DESIGN.md 与本 spec 记录最终规则。数据读取 content/works.ts、content/lines.ts，沿用 React/CSS，不添加依赖。

## 验收与验证
- 首页无浮动产品卡片和旧折叠产品列表；10 件作品可切换且链接正确，分类跳转、首尾循环、播放暂停真实工作。
- 自动播放在离屏/隐藏/悬停/焦点内暂停，手动操作后不抢回控制；减少动态仍可操作。
- 桌面、手机无横向溢出，标题与控制不重叠，键盘可达；检查首屏、作品、方案、关于、文章。
- npm run lint、npm run check、npm test、npm run build；真实浏览器验证上述交互与响应式，不新增自证式静态测试。
- 继续更新既有 owner-only 私有试用网站，GitHub commit/push 沿用会话授权。

## 假设
“滚动播放”按自动选中下一作品并同步滚动列表实现；左图为现有分类主题插画，非每件作品的真实截图。产品目录页保持原行为。
