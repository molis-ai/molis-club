# 内页内容与视觉重设计

## 背景、证据与目标
用户要求使用 Impeccable，结合首页风格重新设计首页之外的内容。当前 Products/Solutions 共用 catalog.tsx 的单调文字行列表，works 详情采用同一大符号块，无法表达作品差异。暂按内页范围推进，首页保留；范围澄清已发出。

## 范围与完成等级
本次为功能可用的视觉重设计：/products（含 line 筛选）、/solutions、全部 /works/[slug]。不修改首页、品牌、登录/联系业务、原文、产品事实、数据库与外部入口。网页保持 Molis AI。既有链接与 metadata/结构化数据保持。

## 场景与关键方案
访客从首页进入产品集，先看可尝试的作品，再按三种使用场景探索；每项明确名称、描述、阶段及详情入口。方案页从业务问题进入，展示三条示意路径和真实边界；产品/方案详情明确为什么做、适合谁、当前可用性，然后进入真实外部链接或反馈。

## 设计合同
模式：产品集 Experience，方案页 Persuade，详情 Read。继承首页暖纸、墨蓝、Geist/Newsreader、真实 Logo 和手绘配图。产品集以可用作品的双栏展开起笔，三条产品线以主题插画、不同密度的开放排版组织；不用后台式表格或全页同尺寸图标卡片。方案页用墨蓝问题区与暖纸工作流展开。详情取消巨幅占位符号，以真实 Logo、作品主张、当前阶段、创作缘由与反馈组成完整阅读路径。动效集中于链接图像轻微推进及原生展开，减少动态时关闭。
用户已授权重新设计，继承明确首页风格；以实际可操作代码切片推进，不增加 Skill 默认多轮概念审批。

## 数据、依赖与边界
content/works.ts 与 lines.ts 是唯一事实；现有四个真实 Logo，其他作品使用名称排版而非假图标；三张主题插画只作场景配图。新增内页样式隔离，首页样式和交互不改。沿用 Vinext SSR、原生 Link/details 与既有 Notes。
允许修改 app/catalog.tsx、app/works/[slug]/page.tsx、新内页样式/展示组件、tests/discovery-http.mjs（更新已替换的 DOM 选择器）、DESIGN.md 和本 spec。无新依赖。

## 验收与验证
- 产品集三条分类及全部10个产品可达，筛选 URL 不变；每个真实阶段/入口保留。
- 三个方案完整说明场景、示意路径、阶段边界与联系入口。
- 13个详情保留原始事实、可用外链和真实反馈，移除大字母占位图。
- 首页品牌及现有版式保持；窄屏不溢出、内容顺序合理、键盘与减少动态可用。
- npm run lint / check / build；原有 discovery HTTP 检查；视觉按桌面/移动一轮检查后集中修正。
- 发布到原 owner-only Sites，未扩大受众。
