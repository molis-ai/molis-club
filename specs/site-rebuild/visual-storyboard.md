# 逐页分镜：用画面讲内容

2026-10-15。负责人看了新站实现（PR #24），说很多页是大段文字平铺，看不下去，像模板。本文只解决「内容怎么讲」：逐页给出开头的勾子、按滚动分的几拍、每拍用什么表达、文案怎么减、诚实标注放在哪。整体视觉风格（配色、字体、质感）另有一边在重新找方向，这里不碰外观令牌，只做结构、动效与可视化，换一套外观也能保留。

信息架构与每页放什么，仍按 `specs/site-rebuild/spec.md`（本地规格）；事实以 `docs/studio-intro.md` 为准。

## 0. 共同做法

**改前的病。** 实看 1440×900 与 390×844 截图（`outputs/visual-story/before/`，不进 Git）：企业合作 9 屏，五个问题、三步合作、四项服务每一块都是「加粗一句 + 两三段」，从第 2 屏起就是整页灰字；团队是 8 张塞满经历的白卡；沿途是 54 行三栏表格，10 屏没有一处停顿；关于 13 屏，六条信念、1.5 表格、1.6、第 2 章都是整段原文；产品页的演示区本来就好看，读不下去的是收尾「当前进展」三栏长句。

**一拍只讲一件事。** 每拍先给一个画面（会动的图示、能动手的东西、一个数字、一组对比、一句大字），再给最多两三行字；原文长段落收进「展开看全文」（原生 `details`，不用 JS 也能开，键盘可用），不删事实。

**文案可以压，事实不变。** 不再要求逐句照抄 studio-intro：压成一句、拆成词、变成图示里的标签都可以；但产品阶段、开放情况、数字（100+、8 年、3 年、54 件……）、谁做过什么、哪件探索在哪，必须和 studio-intro 一致。`tests/site-copy.test.mjs` 改成核对这些事实（见第 11 节）。

**动效的规矩。** 只用原生滚动，不劫持；滚动驱动的画面读 `useSiteMotion` 写进的 `--p`、`--pin`，样式里给默认值 1，所以没有 JS 时停在完整的结果；`prefers-reduced-motion` 时同样直接停在完整的结果；循环的小动画只放几轮就停在最后一帧，或只在视口里、页面可见时跑；能点的都是按钮或链接，键盘能走到；手机 390 宽单独排（竖着走的路线、竖着流的河），不缩成看不清的桌面版。

**可复用的几种画面**（`app/_site/viz/`，只读令牌，不另起颜色字号）：

| 部件 | 用在哪 | 是什么 |
|---|---|---|
| `Fold` 展开看全文 | 各页 | `details` + 一行摘要，展开是原文段落 |
| `HaveNot` 已有 / 还没有 | 产品页「当前进展」、企业合作「内部探索」 | 实心块是已经有的，虚线块是还没有的，一眼看出做到哪；不画百分比，不暗示进度数字 |
| `Converge` 汇流 | 团队「来路」、关于「从哪来」 | 一组点从各自的位置滑到同一列（Molis），滚到哪滑到哪 |
| `Rail` 路线 | 企业合作 | 一条线上几站，走到哪站亮哪站，站下面落下「留下的东西」 |

## 1. 企业合作 `/enterprise`

**勾子（前 5 秒）。** 大字「把 AI 用进业务，把能力留在团队。」旁边直接是一个问题：「你们卡在哪？」五个短选项（不确定从哪投入 / 人手已经排满 / 资料经验拼不起来 / 产品想有 AI 能力 / 想让整个团队会用 AI）。点一个，标题下那条四站小路线立刻亮出建议起点（标「建议」）。访客第一眼就有一件可以做的事，而且是关于自己的。

**节奏。**

1. **首屏**：标题 + 选问题 + 四站小路线（开始前 · 一起做 · 核验 · 交接）。开场三段压成一行三步：「找到值得投入的场景 → 做出可以亲手使用的工具与流程 → 把使用、判断和改进的方法交到团队手里」，原文三段收进「展开看全文」。石廊宽窗留在首屏下面。
2. **五个问题 = 五个症状**：五张小卡，每张一幅用原文名词搭成的小图示，加粗一句当标题，正文收起。
   - 不确定从哪投入：客服、销售、运营、内容、研发五个词，一个问号在它们之间跳，停不下来。
   - 人手排满：一天的进度条被资料准备、信息核对、内容制作、后续跟进塞满、溢出。
   - 资料经验拼不起来：沟通记录、不同文档、老同事脑中三块碎片，各在一角。
   - 产品想有 AI 能力：一个虚线框写着「演示」，想法在框里出不去。
   - 整个团队会用 AI：一排人里只有一个亮着（经验留在个人的聊天记录里）。
   每张卡下有「从这里开始」，点了等于在首屏选了这个问题，并跳到路线。
3. **合作路线（标志性交互）**：桌面上路线钉住，往下滚，一个点沿线走过四站；每到一站，这一站的服务名、适合谁（一句）、做什么（压成一句）浮现，同时把「留下什么」放上路线下方的一格架子——「留在团队手里」：试点方案 → 可试用的工具与流程 → 问题记录、改进建议、复测方法 → 任务说明、检查清单、操作流程。走完，架子满了，回扣标题「把能力留在团队」。5.3 的三步是线上方的三段（I 约定怎样判断成效 / II 在真实任务里调整 / III 核验与交接），每段只露两三个关键词，原文收起。选过的问题在这里亮出「建议起点」和「接着」。手机上路线竖着走，不钉住。
4. **我们也在亲自探索**：CGS、Evrik、Aether 三张卡，大名字 + 虚线章「内部探索，不是客户案例」+ 它回应的那个企业问题 + `HaveNot`（已有 / 还没有，取自 5.4「当前阶段」的两半）+ 阶段签。
5. **做这件事的人**：中间写「把 AI 用进一段业务」，四个方位是 5.5 的四类能力，成员以名字首字字标围在各自方位，点名字链到团队页。一行小字照实写：按合作需要摘的个人经历，不代表固定分工，也不是 Molis 的客户项目或交付成效。
6. **表单**：预选企业合作；首屏选过的问题会带进「想说的事」作为开头（访客可删改）。处理方式照原句。

**文案怎么减。** 开场三段 → 一行三步 + 展开全文；五个问题每个 2 段 → 图示 + 加粗一句 + 展开；5.2 四项服务每项三段 → 适合谁一句、做什么一句、留下什么变成架子上的物件；5.3 三步 8 段 → 每步 2–3 个关键词 + 展开；5.4 表格 → 三张卡；5.5 四段 → 方位图。

**诚实。** 问题 → 起点的对应是建议，页面标「建议」，对应关系待负责人确认（沿用规格第 6 节的表）；内部探索三项每张都盖章；成员信息只用 studio-intro 5.5 的原意，团队真人照片未定，用字标。

## 2. 团队 `/team`

**勾子。** 首屏标题「一群同类，一起创造。」旁边是一张卡：「辞职之后，从北京骑车回南宁的男人。」下面一行：**这句自述是谁的？** 八个名字可以点。猜对了卡片翻出名字和「去看谢俊的卡片」，猜错了一句干幽默「不是 ×× ，再猜」，「换一句」换下一条自述。没有 JS 时答案收在「揭晓」里。

**节奏。**

1. **猜自述**（上面）。题目只用成员自己写的个性标签，排除含本人名字的（如「Google 可以搜到的女人（搜索：赵壮实 数据）」「叫我谢尊」），标注「自述：玩笑话，不作职务」。
2. **来路汇流**（记得住的画面）：一句大字「我们曾是美团的同事。」下面是一张点阵：一行一个人，一列一家公司（美团、字节、小红书、滴滴、LinkedIn、硅谷创业公司、快手、英语流利说、Teambition），点只画 studio-intro 第 7 章写明的经历；美团那一列几乎排满。往下滚，所有点向右滑进最后一列「Molis」，汇成一列——「现在，这些不同的经验聚在 Molis。」杨鹏飞的资料待补，他那一行只有 Molis 一个点，不写任何占位字。
3. **八个人**：一行一个名牌（编号、名字、发起人 / 联合创始人、方向一句），点开是经历全文和「自述」；比原来的大卡短一半，一屏能看到大半个团队。
4. **结尾**：2.1「看同一个产品时，我们会从不同的位置出发，再一起把它做具体。」大字 + 去关于我们、聊一聊。2.5 一段话版收起。

**文案怎么减。** 导语保留；经历全文收进名牌展开；个性标签拆成一行一个，一部分进猜谜。

**诚实。** 不用素材图里的人；没有本人照片，不放头像；徐晶、杨鹏飞没有个性标签，不进猜谜也不留空位；玩笑头衔不作职务；公司点阵只来自第 7 章原文，不推断。

## 3. 沿途 `/along-the-way`

**勾子。** 首屏一个大数字 54，旁边一条河：54 个点从左边八个源头（工作里的问题、做决定之前、交出去之后、工作之外、走进去、作品、交给更多人、设计里）出发，顺着细线流到右边的去处：流进 Molis Work、流进 Molis Tool、流进 Molis Story、留在 Lab、停在设计里、已归档，其余各自留下了一点具体的东西。打开页面就看见点在流；停下来看，哪片水域大一眼就知道。

**节奏。**

1. **河**：标题「那些具体的尝试」+ 一句「有些做出了独立应用，有些留下了可玩的原型，有些停在设计与研究里。」点悬停 / 聚焦显示名字和它关心的问题，点一下跳到下面那一行；点右边的去处，下面的索引就只剩流到那里的几件。手机上河竖着流（源头在上、去处在下）。
2. **索引**：八组，每组一道墨线 + 编号 + 组名 + 一条按去处分色的细条（这一组的东西流去了哪）。每件一行：编号、名字（别名）、它关心的问题、去处章；点开是「现在在哪」的原文和公开仓库链接。筛选条照旧（按去处）。
3. **结尾**：附录 A 最后一段原句。

**文案怎么减。** 开头两段压成一句（第二段原句）+ 展开看全文；每件「现在在哪」收进行内展开，表格三栏变成一行。

**诚实。** 去处严格按附录原文：写明并入哪件产品、Lab、停在设计里、已归档的才归类；没写明的一律归「各自留下了一点具体的东西」（附录最后一段对每一项都成立的说法），不替它们编阶段；同时是独立应用的（Jelly、Cognia、DropAgent、牛来）在点上加一道圈。只有公开仓库给链接。

## 4. 关于我们 `/about`

**勾子。** 首屏大字「Molis AI 是一间做 AI 产品的工作室。」下面四个问题逐行浮现，每个问题右边落下回答它的那件产品（手上的工作能不能接着做 → Work……），第五行虚线：更远的 World。四个问题本来就在 1.3 的第一段里，现在变成一张对照图，是读者自己会在心里回答的问题。

**节奏。**

1. 首屏：标题 + 问题 → 产品对照 + 窗前远眺的人。原「01 我们是谁」并进首屏，不再重复一遍。
2. **从哪来**：`Converge` 画面：产品、数据、研发、架构、业务运营、客户工作六个词从四周汇到「Molis」，配一句「我们曾是美团的同事。」；原文三段收起；链团队。
3. **什么变了**：一排「想法」小点，越来越多被做出来（变成实心块），最后一个圈停在其中一个上——大字「当越来越多想法能够被做出来，选择做什么、为什么做，反而变得更重要。」原文收起；链《人的尺度》。
4. **三种媒介，同一个动作**（原样保留，已经是演示）。
5. **六条信念**：六句加粗大字是一张可点的目录，点哪条在旁边展开哪条全文（手机上是手风琴）；默认展开第一条；没有 JS 时都是 `details`。
6. **落到产品里 + 要求自己**：1.5 四行变成四张「信念 → 产品」小卡（产品名做章）；1.6 四条只留加粗一句，正文收起。两节合为一拍。
7. **接下来去哪**：「一个人的一天」横条：工作（Work、Tool）· 生活（Life）· 体验（Story），滚到哪亮到哪，末尾「人的一天才逐渐完整」；海岸线视频；World 的那个问题放大成一句，链 World（概念设计）。原文收起。
8. 三扇门（原样）。

**文案怎么减。** 13 屏压到约 8 屏；所有原文段落都还在页面里（收起），只是不再一上来铺开。

## 5. 产品页：Work / Tool / Life / Story / World 的「当前进展」

演示区本来就是滚动演示，好看，不动（Work 页主对话那边也在改，这次只改共用的收尾，不碰 `app/(site)/work`）。读不下去的是收尾三栏长句。

**改法。** `ProductEnding` 的「当前进展」换成 `HaveNot`：大号阶段签 + 一句阶段说明；下面两排块——实心块是已经有的（例：Work 的工作台、内置工具、AI 协作能力、数据存在本机），虚线块是还没有的（插件创作仍是预览、团队空间、多设备同步、插件分享、新版正式安装包）；最后一行「现在怎么体验」是一个动作（查看开源代码 / 关注进展），不是一段话。原句收进「展开看原文」。World 只有一个块「概念示意」，其余全是虚线，诚实地空着。

## 6. 社区 `/community`

已经是「作品带着做法」的结构，好看。改两处长段：「从一个可以亲手试的作品开始」的三段导语压成一句 + 展开；「带回来」三栏改成一个回环图：带着好奇来 → 带点什么走 → 再带点什么回来，三种带回来的方式挂在回环的第三段上。方法目录子页是工具页，不动。

## 7. 文章 `/essays`

只有两篇。每篇把文章自己的小标题排成一条「本篇脉络」（《人的尺度》：最后一公里 → 清算日 → 提示词之外 → 过秤 → 换气 → 两个早晨 → 感性的零点），一眼看出这篇怎么走；摘句放大当勾子。仍然无配图、无视差。

## 8. 联系 `/contact`

表单本来就短。把「这张表怎样处理」的几行字换成一条三步小图：你写下几句 → 存进团队私密收件箱（不公开展示）→ 目前不会自动回信。字句照原句。

## 9. 首页（前两屏之后）

## 11. 测试怎么改

`tests/site-copy.test.mjs` 原来逐句核对「原句一字不差」。文案压缩以后改成核对事实：

- 页面文案里出现的每个数字（8 年、3 年、100+、54、10 任……）都能在 studio-intro 里找到，不凭空出现数字。

- 沿途每一件的名字、别名在附录 A 里；归到「流进 Work / Tool / Story」的，附录原文里那一件后面确实写了并入那件产品；Lab、设计里、已归档同理；总数 54。

- 仍标为原句的部分（工作室、产品正文等）继续逐句核对；内部编辑备注、待补占位、未定口径（如「月百万+」）不出现在任何页面文案里。
