## 2. 设计概念与理念

**一间开着窗的白房子。** 界面是白房子：近白的纸、细字、细线、大量留白（推敲与克制）。配图是窗：窗外是自然与人（温度与生命）。房子里的人是作者：产品演示、团队、社区作品都是「被做出来的东西」。

《黑客与画家》落到细节的方式：

| 理念                                     | 网站上的做法                                                                                                                                                         |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 编程也是创作，代码、颜料、文字是不同媒介 | 产品像作品一样标注「名称 · 形态 · 阶段」（展签式写法）；关于页让作画、写代码、改文字并排演同一个动作（起稿 → 修改 → 完成），三者地位相同；不把技术与人文分成两种版式 |
| 挑剔的品味 + 实现能力；简单来自推敲      | 看不见的地方也当作品设计：404、焦点框、选中色、打印样式、替代文字、空状态与报错措辞、减少动态时的画面；中文标点挤压、标题平衡断行、等宽数字                          |
| 高级与昂贵材料无关                       | 只有三档字重、一种强调色、1px 线、一套圆角；不用磨砂玻璃、胶片颗粒、渐变光晕、三维、层叠投影                                                                         |
| 智性的玩心与一点不驯；真独立，不表演怪   | 每页一处有用的大胆决定（超大编号、打破网格的一句、突然开满整屏的窗）；每个惊喜都要演示点什么；团队自述、404、空状态带干幽默；源码与控制台给同类留一句话              |
| 创造落到人的实际体验，在使用里校准       | 原生滚动不劫持；无 JS 内容可读；键盘可用；字号不为好看牺牲可读；演示标「示意」；页尾写「本页最近修改：日期」（取真实日期）                                           |
| 好设计像自然                             | 动效像物体落定；光从上方来；温度只来自照片里真实的光，界面不画假光影                                                                                                 |

## 4. 首页

1. **首屏**（已定）。
2. **Warmware**（已定）。
3. **产品**：纸页升上来盖住画面（沿用 r8）。右侧舞台：名字与阶段 → 第 4 章标题 → 一句「它是什么」→ 演示 → 去处。舞台底部细线表示第几段，点哪条看哪段；只在选中、在视口里、没暂停时播；减少动态停在每段结果上。产品之间的联系、「目前如何了解与体验」不放首页。
   - **Work 五段**（每段约 3.5 秒，一轮 ≤18 秒；Work 是核心产品，可以长一点）：
     1. 「你和 AI，接着同一份内容工作。」写到一半的方案，助理接着当前内容整理提纲，改动高亮；你点「接手」，自己改一句。
     2. 「助理调用几个插件，把事情接着做完。」（新写，待确认）助理从信息流取三篇资料，在数据表里做成对比，再生成一页汇报，三样成果落进项目。
     3. 「工作台也可以长出你自己的工具。」你说一句需要，一个插件被做出来、过检查，装进工作台成为一块界面，助理也能用它。标「预览」。
     4. 「一起讨论，上下文和成果都接得上。」（新写，待确认）右侧「讨论」里同事引用那页汇报开了个话题；结论回到项目，谁接着做都看得到前因后果。标阶段（见第 9 节）。
     5. 「你不在的时候，助理接着干。」（新写，待确认）你下线后，助理按 Goal 跟进到期的事，第二天只把需要你决定的一件留在 Inbox，写明原因。标「开发中」。
   - **其余各一个 case**（一轮 6–8 秒）：
     - Tool：选中一段活动信息 → 光标旁弹出动作条 → 整理成日程草稿（第 4 章说这是正在打磨的场景，标「界面示意」）。
     - Life：「想陪妈妈去看海」先留着；空出半天，它带着「为什么此刻想到」冒出来，给近一点 / 多走一段两种准备，你来定。
     - Story：彼处——从一个「如果」走进一本逐章展开的书，归来时写下一句话，落进「此处」。
     - World：常去的面馆放进小岛，后厨的门通向另一座城，纪念物带回来摆在旁边。标「概念示意」。
4. **我们相信**：纯白，六条信念只放加粗的那一句，大字，随滚动逐条变成墨色（第一条是「有自己的判断，也有把它做成的本事。」），链到 `/about`。
5. **结尾**（2026-10-22 / 10-24 改）：一屏。上部铺一张照片（薄雾里的远山，草坡山脊上远远站着一个人），天的上沿化进上一屏的纸里，过渡句「让口味相近的人认出彼此。」写在空着的天上；照片下面的纸上三张白卡横排——企业合作 / 社区 / 关于我们，整张卡是链接，只留一颗圆形箭头。手机上照片另裁，让那个人留在画面里，卡片竖排。画室影像挪去社区结尾。
6. **页尾**。

## 5. 产品页

### 5.1 共同规则

- **主线**：每页跟着「一件事」从头走到尾，第 4 章各节是这件事里的一个个时刻；不按「亮点 / 功能 / 场景 / 比较」分组。
- **首页演一遍，产品页亲手做一遍**：首页 case 是产品页故事的缩略版；产品页在故事最关键处让访客亲手做一次（标志性交互）。
- **演示机制**：桌面左文右图，右侧画面钉住；滚到哪一章画面换到哪一章，一章两三步，滚到哪一步演到哪一步，可以倒回；手机上画面在每章文字上方，进入视口按时间播，可暂停；减少动态停在每步结果。画面一律标「界面示意 / 原型示意 / 概念示意」。
- **固定收尾**：适合这样的时刻 → 当前进展（已经有的 / 还没有的 / 现在怎么体验）→ 和其他产品的关系（只在有关系的页）→ 去处。不放附录 A 的「来路」。
- **能变的与不能变的**：顶栏、页尾、字体字阶、网格边距、标签与诚实标注、按钮链接、缓动曲线不能变；演示区主色调、画面形状、页面节奏、标志性交互可以按产品变，但整体不能突兀——产品特色只放在演示区和窗里。
- **首屏**：左边产品名（Jost 展示字号）、第 4 章标题、加粗一句、作品标签「名称 · 形态 · 阶段」；右边这件产品的窗。

### 5.2 各产品

**Molis Work** —— 最「满」的一页，像一张真的工作台，主色木色与植物绿。给持续推进一段工作的人；看完知道工作能在人、工具与 AI 之间不断线地继续，现在能看开源代码。主线：一份「行业观察报告」走三天。

| 章节                                         | 画面                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 开场：一份方案跨过许多天、几个工具和 AI 会话 | 散在浏览器标签、聊天、文档、待办里的碎片收拢进同一张工作台                                 |
| 按这段工作的需要，布置工作台                 | 项目装上资料、信息流、文档；个人日历、笔记、待办始终在；一个词搜出各工具里的结果           |
| 你和 AI，接着同一份内容工作                  | 助理整理，改动看得见；你接手改一句；需要判断的交回你                                       |
| 助理用插件把事情做完（新）                   | 信息流 → 数据表对比 → 汇报页 → 日历约评审 → 待办留跟进；成果都在项目里、有来源             |
| 工作台也可以长出你自己的工具（预览）         | 描述 → Agent 给方案、沙箱里做 → 检查验收 → 装进项目，助理和获授权的 Agent 能调用           |
| 一起讨论，上下文跟着走（新）                 | 群聊里从一条消息开话题，引用文档段落与成果，结论带回项目                                   |
| 有记录也有依据                               | Goal 记目标、进展、问题、待决定；换 Codex / Claude Code 也读同一份记录接着做；收尾逐条核对 |
| 你不在时，助理接着干（新，开发中）           | 跟进到期、失败时提醒、守勿扰，只留需要你判断的                                             |

标志性交互「把这件工作交给谁」：访客把一张工作卡交给助理 / Codex / 群里的同事 / 自己，资料、进展、成果、讨论原样跟过去，接手方从断点继续，需要判断时卡回到你手里。去处：查看开源代码 · 从源码构建说明 · 关注新版进展。当前进展照第 4.1 节：新版尚无正式安装包，公开历史版本与新工作台分开说明。

**Molis Tool** —— 最空、最短的一页，几乎全白，一道光。给手上已有材料的 Mac 用户。主线：一个下午手边冒出的几件小事。开场：老路四步（开应用、搬材料、找功能、带回来）vs 一步；眼前的小事（清理文字、PDF 取几页标「副本处理，原件保留」、处理图片，每个动作标「本机 / AI」）；结果接着用（PDF→文字→表格→比较或导出）；收起来再回来（菜单栏、「接续」里的材料、草稿、结果与来源）。标志性交互：整页任意选中一句话，动作条出现在光标旁（结果为示意）。当前进展里写：计划成为 Work 的基础能力，范围与时间未定。

**Molis Life** —— 节奏最慢、留白最多，主色海水浅蓝与沙色。给被琐事占着心、又有一直想做的事的人。主线：几周里的一件挂念和一个心愿。开场：没退回的款、快到期的事、说了很久的愿望；挂念有下文（退换货四阶段，「已提交 / 已受理 / 已到账」有依据才亮）；想做的事找到机会（看海）；给好奇心留位置（植物、书、音乐，替我处理 / 一起想想 / 先留着，「它对你的理解」可改）。标志性交互：拨动「这周空出多少时间」——两小时给近一点、半天给多走一段，每次附「为什么此刻想到」，去不去由你点。当前进展里写：Life + Story = World 是未来方向，尚未打通。

**Molis Story** —— 唯一允许变深变浓的一页，但只在窗里面。页面本身就是「此处」（去过哪里、未完旅程、带回了什么）。四个世界各一扇拱窗：滚进去窗放大到整屏（走进去），换成这个世界的颜色和概念画面，演一个瞬间（云海来客：一来一回的信号；彼处：逐页翻开的书；袖珍博物馆：照片摆进展厅、写展签；雾港：柜台上的失物和两个选择，下一夜留下后果）；再滚画面收回成窗，回到白纸。之后「每个世界都有自己的节奏」「归来」，更远的方向（带 Agent 同行、创作者做世界）标「尚未开放」。标志性交互：带回的纪念物真的落进页面顶部「此处」的清单。

**Molis World** —— 像一张绘图桌：铅笔线、虚线框，故意保留未完成的样子。概念页，篇幅短。主线：一个地方慢慢长大（面馆 → 取名布置 → 后厨通向另一座城 → 纪念物带回 → 「这个周末，真的去吃一次吧」→ Life + Story = World，连接尚未实现）。标志性交互：把一个地方放进小岛。去处只有「关注进展」。整页标「概念设计 / 概念示意」。

## 7. 视觉系统

- **颜色**：近白略暖的纸（白盒子的近白，替换 r8 沙色）；次一级面稍深一档；暖黑文字三档（正文 / 次要 / 辅助，辅助色对比度 ≥4.5:1）；线为 12% 墨色；强调色只有 Logo 杏橙，只做状态圆点、细线、选中淡底；需要写字用深一档杏橙。阴影带暖色、极少用。
- **字体**：三档字重（300 / 400 / 500），层级靠字号、深浅、留白；300 只用于 18px（中文 20px）以上；长文正文 400；编号与图注用 Jost 细斜体；中文不斜体，英文标题不全大写，英文小标签全大写加字距。字阶参考白盒子规范第 3.3 节，不随手加新字号。
- **版式**：12 栏网格，刻意不对称（标签在左两栏，正文偏中）；一屏一件事；区块开头一道 1px 墨线 + 细斜体编号 + 一行小标签 + 大标题；版心 1440，阅读栏约 40rem。
- **配图当窗**：除首页前两屏外，配图不当背景、不压字；是有比例的窗（竖 4:5、宽 21:9），四周留白，文字在窗外白底；进入视口时从一道窄缝开到完整；每张配一行细斜体图注；统一一档轻调色（暖一点、对比低一点），把 AI 生成图和摄影拉进同一色调；载入前铺该图平均色。
- **组件**：墨色实心胶囊按钮（唯一实心元素）；文字链接悬停时下划线从左画到右；状态签带杏橙圆点；诚实标注为虚线胶囊（示意、预览、概念设计、示例数据）；作品标签「名称 · 形态 · 阶段」；卡片白底几乎无阴影。
- **动效**：只有三种动作——开窗（画面打开）、浮现（淡入并上移 12–18px）、演示（产品画面）——加悬停小反馈；全站一条缓动曲线（开头快、收尾慢）；原生滚动 + 跟随缓动与 S 形曲线（沿用 r8）；页面切换交叉淡入、顶栏不动；循环动画离开视口或页面隐藏时停；减少动态时每处停在完整结果。
- **留下**：r8 的首页前两屏、产品列表结构、纸页升起、结尾开窗、页尾被裁一截的大字标；白盒子的近白、细字、单一强调色、区块编号、展签式标注、留白。**去掉**：磨砂玻璃、胶片颗粒、沙色、画面暗色压层（已定首屏除外）、三维展厅、画框、树影动画、评审用的方向切换条。
