# 烤个梨呀：创造者社区重建

日期：2026-09-06。执行授权：重新设计、实现并部署试用，调研最低成本的前后端方案。

## 目标与证据
愿景：让更多人有勇气成为创造者，让有生命力的作品找到最早相信它的人。依据 article/11-落地主义 两篇原文及 2026-09-06 GitHub adeptify 仓库和精选 README。旧仓库只有静态设计，无真实后端。

## 完成等级与范围
本轮为等级 3「功能可用」的私有试用网站：首页策展、作品筛选与详情、两篇原文阅读、团队故事、作品留言、加入申请、持久化数据库、部署。公开产品的完整身份、审核、通知和运营后台不在本轮，不宣称完整社区已上线。
保留社区名称、愿景、真实产品事实；替换视觉和导航；忽略旧首页设计和旧产品成熟度假设。旧探索文件作为历史保留但不进入新部署。

## 使用场景与方案
- 访客浏览作品，按趣味作品/开发工具筛选，进入详情，访问已验证的公开仓库或发布页。
- 私有试用访客为具体作品署名留言；新请求经服务端校验写入 D1，刷新仍可读。明确署名未验证。
- 想参与的人填写称呼、邮箱、角色、想做的东西；申请私密存储，不将邮箱公开，不承诺已通知团队。
- 读者进入两篇文章，阅读正文而非发布配套或私有仓库附录。

## 实现边界
新代码全部在 community/。React + Vinext + Cloudflare Workers，D1 通过 Sites 管理；无需模型 API。内容从本地原文与仓库核实，数据库只保存参与内容。网站由 Sites 私有部署，后续可迁移自有 Cloudflare 账号。根 README 和 DESIGN 更新入口与设计事实。

## 输入、输出和约束
留言输入作品 slug、称呼、文本、客户端生成请求 id；参数化 SQL，唯一 id 避免重复提交，长度限制，同源写入。加入申请有邮箱校验和唯一邮箱约束，重试不会重复记录。无假帖子、用户数、星标数、试用入口。无公开私有仓库地址、私人环境路径、密钥。数据库失败应提示重试，保留表单。

## 验收
1. 首页与详情/文章/加入路径可访问，真实状态和来源正确。
2. 留言写入后返回保存内容，GET 可读取；无效输入拒绝，不发生持久化；重复请求不重复创建。
3. 加入申请可保存、不公开邮箱；重复提交不重复创建。
4. 生产构建与定向 API 验证通过；移动布局、键盘焦点和错误状态有实现；视觉验证遵循当前工具能力。
5. 部署成功并返回实际 URL，注明私有访问范围。
6. 部署方案列出免费额度、额外费用、上线条件、成本升级触发点。

验证：npm run build；npx tsc --noEmit；node --test tests/*.test.mjs；本地 HTTP 启动检查；Sites 部署状态及数据库读回。

开放项：正式域名、公开访问、GitHub OAuth 应用、审核负责人，均不阻塞私有试用。
