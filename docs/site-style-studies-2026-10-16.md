## 样张范围与设计依据

- **社区**：保留可玩的花、四件作品、方法目录、分享入口和结尾；收掉粗边框、硬投影、票根及印章的强调，使照片、作品和文字回到同一套官网视觉里。角色可以保留，但不与作品争夺注意力。
- **Tool**：沿用现有四章及滚动演示，用图左文右作对照，舞台尺寸保持稳定；不改产品能力、阶段和示意标注，不影响其他产品页。
- **联系页**：补齐含公共页尾的紧凑桌面样张，保留五种来意、产品选择、两类同意项、处理说明、页尾目录与日期。手机仍按内容自然展开。
- **页尾**：历史上提供过去图标及介绍的对照；当前已采用无图标、左侧大字标、单句「技术，回到人的尺度。」与右目录，minimal 只作未采用的无口号对照。
- **关于**：只取现有六条信念作为阅读实验。桌面左侧固定画面，右侧六段原文随原生滚动顺序阅读，前后回看时画面对应；手机与无 JavaScript 时按图文顺序完整展开。不采用第 09 项总览重组或第 02 项候选文案。

沿用现有视觉令牌：纸色 `#fbfaf7`、白 `#ffffff`、墨色 `#1b1a18`、辅助字 `#69665f`、细线 `#d8d5ce`、杏橙 `#ea9260`。字体继续为 Jost 与系统中文，细字、留白、照片作为窗；不新增字体、图片、视频、依赖或动画框架。

复杂度取舍：社区用独立作用域样式复用原交互；Tool 给已有章节组件增加可选布局；关于复用现有图文内容与媒体组件，新增局部滚动联动。普通 URL 保持现版，明确参数才进入样张，避免复制整站或在默认页面直接替换尚未验收的方案。

## 验收方式

1. 社区同尺寸对照首屏、作品区、方法目录、分享区和结尾。实际拖动或用键盘改变花、换色、带走 SVG，核对晾衣绳同步；逐一切换四件作品，检查示意、暂停、方法搜索、复制、下载和分享入口。
2. Tool 前后滚动四章，核对章节与演示每一步，观察左图右文是否比现版容易读；手机可顺序读完，减少动态、无 JavaScript 保留说明与完整结果。
3. 关于顺序读完六条原文并向上回看，核对图片对应、末段衔接和舞台是否遮挡；手机、键盘和无 JavaScript 可读完整，原版标签页与 `#beliefs` 仍可到达。2026-10-18 用户明确删除「我们怎样要求自己」整段及入口，`#demands` 已撤下，不再作为验收目标。
4. 联系页在桌面依次选择五种来意，特别检查关注产品的额外选项、分享的展示同意、错误反馈及页尾；窄屏可自然滚动，不能为一屏而裁内容。
5. 页尾当前首页桌面排版已通过，不重复要求用户选择旧的两句介绍方案；跨页面与设备需验证时保留目录目的地、首页入口和最近修改日期。
6. 默认 URL 和“现版”不能受到样张 CSS 影响；不出现横向溢出、图片文本遮挡或滚轮被拦截。

工程验证、已实际覆盖路径和未验证项在实施完成后记入下节。视觉取舍和阅读感受由用户验收，不能以构建通过代替。
