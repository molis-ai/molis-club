# Molis AI 产品线分类

2026-09-06；根据 adeptify GitHub 仓库列表、README 与产品说明整理。仓库描述可能过时：Flyleaf 已按当前 README 修正为应用交互 Runtime。

| 一级 | 产品线 / 场景 | 首批网站条目 | 为什么放在这里 |
|---|---|---|---|
| Products | 情绪与体验 | Elsewhere、Seentoo（见过）、ASTRALO | 回应陪伴、好奇与人与人的连接；游戏也归这一线 |
| Products | 轻量工具 | niul.ai、DropAgent、Jelly | 高频、小范围、低使用负担的桌面和个人工具 |
| Products | AI 与工程效率 | Prologue、Flyleaf、ForkLight、GoalBoard | 帮开发者和创造者搭建、执行、协作；底座与工作区同属此线 |
| Solutions | 内容与增长 | Content Growth | 研究、机会判断、内容创作与反馈学习形成工作流 |
| Solutions | 软件 Agent 化 | Evrik | 复用既有软件业务和权限，让系统承接目标 |
| Solutions | 数据与洞察 | Aether | 指标、知识、分析与报告连成业务路径 |

Products 面向“拿来使用的一个产品”；Solutions 面向“要解决的一个业务问题”。分类是对外介绍方式，不宣称这三个解决方案已经可商业交付。各条目仍展示实际阶段。

首批刻意保留10个产品、3项方案；不把所有组织仓库都当作现役产品发布。私有仓库可以在当前私有预览展示用户授权的概要，但不挂无法访问的源码链接。

## 其余仓库的候选位置

这些只形成目录建议，本轮未把未核实的能力或成熟度填入官网：
- 情绪与体验候选：scroll-of-beings、footballnia、log-in-to-log-out、dogfood、pick-one；需要逐个确认是否仍是当前投入项目。
- AI 与工程效率候选：Cognia、Hearth、Relay、Alchemist、Arena；有清楚用途，但要确认与三条线的优先级及互相边界。
- Solutions候选：complai 可放合规审计；DreamStudio 可评估影视创作方案，需先核实当前可交付内容。
- 内部工程/资料/历史不列产品：article、lab、studio-growth、goalboard-casebook、dsh-ecosystem-monitor、已归档 auto-research-workbench、站点仓库本身、外部资料镜像 CL4R1T4S 等。

## 内容依据与发布边界

Jelly 已核实 GitHub Releases v0.3.6，但签名、公证与完整升级仍未宣称完成。DropAgent 已有macOS目录、需求与原型，仅标开发中。Prologue 核心调用已验证；Flyleaf 为桌面框架阶段。Content Growth 仅部分能力验证；Evrik 是固定真实目标的内部技术切片；Aether 是方案设计阶段。品牌改名不改变这些事实。
