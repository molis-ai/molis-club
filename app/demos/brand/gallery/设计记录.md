# 白盒子美术馆官网

2026-10-13。用户在第六版（白盒子美术馆）与第七版（精修）之后，要一套完整官网：内容按 Folio 最新版（`782b84a`，`specs/folio-studio-home/spec.md` 阶段 1–4 与 P1 定稿），视觉统一用白盒子美术馆，但每页的布局与动效按它要传达的内容单独设计。本地预览，未提交、未发布。入口：`/demos/brand/gallery`。第七版首页 `/demos/brand/r7` 原样保留，用来和第六版对照。

## 统一的视觉

- **墙与光**：近白的墙（`--paper #fbfaf7`、`--wall #ebe9e3`），黑字（`--ink #1b1a18`），唯一的颜色是 Logo 的杏橙 `--accent #ea9260`（深一档 `--accent-ink #b5623a`）。作品内部可以有自己的颜色（例如 Story 的世界、Life 的水彩），界面本身不加别的颜色。
- **字体**：界面与标题是圆润的无衬线，默认 Figtree，右下角 Aa 可切 Nunito、Outfit（`--sans`，字体由 `.g[data-font]` 决定）；编号、作品名、图注用 Fraunces 柔边斜体（`--serif` + 类名 `g-soft`，或 `font-variation-settings: 'SOFT' 100, 'WONK' 0`）；中文是系统黑体。
- **展厅**：`Room` 是 CSS 三维搭的纯白盒子：哑光白墙、上方一片柔光、浅色水泥地、墙角极淡的暗，墙上和地上有随风晃的树影（`leaves.ts` 程序生成后烘成两张位图）。没有灯具、木地板、长凳。作品挂在正墙上，`floor` 可以放立在地上的物件（例如首页 World 的展台）；900px 以下自动变成一面平的墙加一截浅色地面。`Wall` 是同样光与树影的一块平墙。
- **物件**：展签（`WallLabel` / `.g-label`）、区块名牌（`Plate`：墨线、柔边斜体编号、大标题）、画框（`Framed`：橡木 / 白漆 / 黑铝 + 宽卡纸）、图注（`Caption`）、圆角按钮（`Btn`）、细下划线链接（`More`）、状态签（`Status`）、诚实标注（`Tag`，虚线描边：规划中、概念设计、示意、示例数据）、下一间展厅（`NextRoom`）。
- **展览的说法**：Work、Tool、Life、Story 是 Room 1–4，World 是还在筹备的 Room 5；作品的「媒介」（三联版画、墙面文字……）是展览隐喻，只作装饰标注，不是新的产品说法。

## 公共部件（只由主会话改）

- `routes.ts`：全部站内地址。整站链接只指向 `/demos/brand/gallery/...`，社区（含方法详情与艺术家）也在站内；外链（GitHub、安装、公众号）照旧。
- `kit.tsx`：`Shell`（顶栏、main、页尾、字体切换；`current` 标当前栏目，`rooms` 打开树影位图，`ending` 放页尾上方的结尾，`compact` 用于很短的页面）、`useGalleryMotion`（`[data-scene]` 写 `--p`：pin / pass / enter / leave；`[data-reveal]` 进入视口加 `is-in`；`[data-parallax]` 写 `--mx`、`--my`；减少动态时 pin/pass/enter 为 1、leave 为 0）、`Room` 与上面的小部件。
- `gallery.css`：令牌与公共样式。首页专用：`home-say.tsx`（品牌一句话）、`home-deck.tsx`（卡牌导览）、`home-rooms.tsx`（五件作品与平面图）、`home.css`。`home-works.tsx` 与 `art-r7.css` 是第一版首页的作品，Work、Life、Tool 页还在用，等这几页重做时再收。
- 在页面里用展厅：外层 `section data-scene="pin"`（高度如 220vh），里面 `div.g-stage`（粘在视口），再放 `Room`；在页面样式里由 `--p` 算出 `--d`（推镜 0…1），例如 `--d: clamp(0, (var(--p) - 0.05) / 0.6, 1)`。挂画比例是 `.g-hang` 的 `--zoom`（默认 1.5）乘 `--fit`。

## 规矩

- 样式：每页一个自己的样式文件，类名一律 `g-页面名-` 前缀（例如 `g-work-`）。客户端跳转后旧页面的样式还在文档里，所以不写裸元素选择器、不重新定义 `g-` 公共类。
- 内容：文案全部来自 `content/`，与 Folio 同一页读同一份；不新增产品事实。Folio 上的诚实标注（规划中、概念设计、示意、示例数据、界面示意、概念稿）原样保留。展览隐喻的小字（Room n、媒介名）用 `aria-hidden` 或明显是装饰。
- 每页一个 h1；页面标题与描述写在该路由的 `layout.tsx`，与 Folio 对应页一致。
- 动效：只用原生滚动，不劫持；不在视口或页面隐藏时停止循环动画；`prefers-reduced-motion` 下停在完整的静态结果，粘性编排取消。
- 图片：可用 `public/` 里已有的图（原生 `img`，声明宽高，按需 `loading="lazy"`）；不新增依赖，新画面用 DOM、SVG、CSS 画。
- 390px 无横向溢出；键盘可达，焦点可见。

## 第三轮：首页重做（2026-10-13）

用户反馈：第二版首页不如第六版；木地板和顶灯显得廉价；除 Story 外的作品看不懂或没有交互感（Tool 光标不动、Life 只是清单）；World 要和其他展厅一样在展览里；首页的链接点不动。之后改为逐页先讲方案、确认后再做。首页方案确认的要点与实现：

- **回到白盒子**：去掉木地板、顶灯、灯轨、长凳、颗粒；光是上方一片柔光加「树影婆娑」，树影远近两层、不同节奏晃动，减少动态时静止。
- **点不动的原因**：三维镜头容器 `.g-cam` 在墙的前面挡住了点击，改为只有 `.g-hang` 接收点击；另有一次是开发服务器的依赖缓存过期（504），重启即可。逐个展签链接做了命中测试并实点跳转。
- **首屏**：只有大字标、三个关键词和展厅照片，去掉「看看我们在做什么」按钮。
- **品牌一句话**（替代工作室身份说明，那段文字之后放到团队页）：前后试过四轮独立的过渡段（对比页 `/demos/brand/gallery/say-lab` 是第三轮的九个效果），最后定为首屏墙上那件作品的第二幕。首屏右墙的展签只写「Molis AI / We build _not only_ software,」。首屏是 330vh 的滚动：第一幕照片放大、镜头推到 A/I 墙前停一会儿；第二幕镜头横移、走近那张展签（展签钉在墙上不动，动的是镜头，位移由 `useLabelWalk` 按展签在墙上的实际位置量出），A/I 随镜头移出画面左边、淡一些；展签下面多出一行跑马灯（Warm ware · Human ware · … · _x_‑ware，16 秒一圈，两端渐隐）；展签是一张有纸边和贴墙阴影的薄卡，树影也从它上面扫过；最后一段镜头再往前挪一点，然后产品导览接上。窄屏和减少动态时不走镜头，展签直接带着跑马灯。
- **卡牌导览**：五间展厅是一副牌，滚到时从一摞依次发开；牌角有点数（右下角倒过来）、里面一圈细框，画心是作品缩影，悬停时牌倾斜、表面一道光跟着鼠标、缩影动一下；World 是虚线牌面。
- **五件作品**：Work 是一块背光灯箱（插件随镜头推近一块块拼上；打字 → 助理递卡 → 光标点执行 → 三条反馈带出处落进来 → 建好待办）；Tool 是墙面文字（光标按那句话实际排版的位置拖选、松开、动作条弹出、点翻译、译文卡贴上墙）；Life 是双联画（傍晚海边的水彩 + 便笺「想陪妈妈去看海」，天放晴的那一步云散开，四步依次亮起，每步标示意）；Story 沿用色域画，走近时中间的缝像门缝一样亮；World 是展厅地上的白色展台和玻璃罩里的方案模型，进来时模型一块块升起、三面小旗竖起来。
- **墙上作品顶格出界（用户在约 1200 宽的窗口里发现）**：原来挂画比例只按几档屏幕宽度写死，墙的实际宽高还取决于窗口比例，中间宽度下 Tool、Work、Life 整组超出正墙。改为 `Room` 按排出来的大小算缩小系数 `--auto`，整组最多占正墙宽 84%、高 76%；展厅推镜推得更近（`--T: 1280`），缩小后展签的字仍看得清。World 的展台改为按视口高、宽里较小的一边定尺寸，不再挡住墙上的字和展签。
