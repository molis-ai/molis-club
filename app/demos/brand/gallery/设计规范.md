# Molis AI 官网设计规范

白盒子美术馆的整站规范。作用域是 `/demos/brand/gallery` 及其全部子页面；`DESIGN.md` 里的 A / B / C 三版不受影响。等这一版成为正式官网，本文再并入 `DESIGN.md`。

相关文件：`设计记录.md`（每一轮做了什么、为什么）、`gallery.css`（令牌与公共样式）、`kit.tsx`（公共部件）、`type-lab/`（字体方向对比页，选定的是第 4 套）。

**本文的状态**：字体部分是新定的，其余部分写的是现有页面已经在用的做法。和现状不一致的地方都标了「待改」，汇总在第 12 节，等内容定稿后一起改。

## 1. 概述

### 一座小美术馆

官网是一座白盒子美术馆：哑光白墙、上方一片柔光、墙上随风晃的树影。五件产品是五间展厅（Work、Tool、Life、Story 是 Room 1–4，World 是筹备中的 Room 5），每件产品挂在墙上，旁边一块展签。访客按自己的节奏走，镜头跟着滚动推近。

### 三个原则

- **作品先于说明**：先让人看见作品与名字，再读一句话、状态和去处。完整说明留在产品页。
- **安静，但不冷**：近白、黑字、大量留白；温度来自柔光、树影、细而圆的字，以及作品自己的颜色，不来自装饰。
- **诚实**：展览是隐喻，产品事实来自 `content/`。规划中、概念设计、示意、示例数据这些标注，一个都不能少。

### 「留白」字体的意思

细而圆的几何字，像展墙上的刻字：字重轻，字距放开，层级靠字号、颜色深浅和四周的空白来建立。它让墙和作品成为主角，字退后一步。细体容易显得冷，所以用 Jost 圆的字形、苹方柔和的笔画和暖白的底来平衡；英文标题不用全大写。

- 杏橙只做点：圆点、细线、悬停时 10–16% 的淡底（`rgb(234 146 96 / 0.1)`）。不做大面积底色，不做正文颜色。
- 作品可以有自己的颜色（Story 的色域、Life 的水彩、Work 的灯箱），界面本身不加别的颜色。
- 阴影带暖色（`rgb(40 30 20 / …)`），不用纯黑。
- **为什么要调 `mute` 和 `accent-ink`**：细字重的笔画更细，看起来比同色的常规字更浅。现在的 `mute` 在纸色上对比度 4.22:1，在墙色上只有 3.63:1，都不到小字要求的 4.5:1。调到 `#69665f` 后是 5.49:1 和 4.72:1；`accent-ink` 调到 `#a4552f` 后在纸色上是 5.13:1。`ink` 16.7:1、`ink-2` 10.5:1，不用动。

## 3. 字体（留白）

### 3.1 字体

| 用途       | 字体                                                                   | 说明                                                                 |
| ---------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 英文与数字 | Jost                                                                   | 几何、字形圆。载入 300 / 400 / 500 和斜体，`next/font/google` 自托管 |
| 中文       | `'PingFang SC', 'Hiragino Sans GB', 'Noto Sans SC', 'Microsoft YaHei'` | 系统字体，不下载。苹方有细体（300）；Windows 回退到微软雅黑细体      |
| 编号与图注 | Jost Italic 300                                                        | 取代现在的 Fraunces 柔边斜体：Room n、牌角点数、图注标题、平面图编号 |

字体栈写在 `.g` 上：`--latin: Jost`，`--sans: var(--latin), 中文栈, sans-serif`，`--serif` 改名为 `--italic`，值是 `var(--latin)` 加 `font-style: italic`。全站不再出现衬线字体。

### 3.2 字重：只有三档

- **300 细体**：大字标、展示标题、区块标题、中文大句、导语、编号斜体。
- **400 常规**：正文、卡片与展签上的名字、导航、链接、小字、标签。
- **500 中等**：只给按钮文字和 11–12px 的标签，保证小字可读。
- 不用 600 及以上。层级靠字号、`ink → ink-2 → mute` 的深浅和留白，不靠加粗。
- 300 只用在 18px 及以上（中文 20px 及以上）；更小的字一律 400。`mute` 色的字至少 400。

- **字阶之外不新增大字号**：现在各页有约 40 种不同的 `clamp()` 标题字号（**待改**），换字时合并到上表。

### 3.4 中英混排

- 中文为主的行里，英文跟着中文的字号走，不单独放大或缩小。只有纯英文的大字（字标、产品名、Products）按英文字阶走。
- 中文大字给正字距（0.04–0.08em），英文大字给负字距（−0.015 到 −0.02em）。苹方细体本来就松，大字再收紧会挤。
- 中文不斜体（浏览器会做伪斜体）；斜体只给英文与数字。
- 中文标题用 `Phrases` 在逗号、顿号、句号后断行，不在词中间折开；标点用全角，按 `content/` 原文。
- 英文标签全大写加 0.22em 字距；英文标题和产品名不全大写，全大写的细体会显得冷。

## 4. 版式与网格

- **版心**：`.g-wrap` 最宽 1440px，`.g-narrow` 最宽 760px（阅读），左右 `--gutter`：`clamp(16px, 3.9vw, 56px)`。
- **区块节奏**：上 `clamp(96px, 14vh, 168px)`，下 `clamp(72px, 10vh, 128px)`；结尾大句上留 `clamp(110px, 16vh, 180px)`。留白宁多勿少，一屏只说一件事。
- **间距**：以 4 的倍数为主，常用 4、8、12、16、24、32、44、56、64、96、128。
- **区块开头**用名牌（`Plate`）：上方一道 1px 墨线，左边斜体编号，右边一行小字，下面是大标题，标题右侧可以放一段说明。
- **栏**：不用固定栅格，按内容开放分栏。常用的有：页尾 1 : 1.4、首页结尾三等分、卡牌五等分、产品页图文各半。900px 以下全部转单列。
- **首屏**：顶栏 64px，下面是大字标与关键词（上沿高 `clamp(236px, 31svh, 300px)`），再下面一张展厅「照片」，四周留出纸色边框，往下走边框退开、照片放大成整个视野。
- **每页一个 h1**；页面标题与描述写在该路由的 `layout.tsx`。

## 5. 空间：展厅、墙与光

- **展厅 `Room`**：CSS 三维搭的纯白盒子。正墙是三层渐变：上方一片柔光，四角极淡的暗，墙脚一道影缝。左墙背光略暗，右墙迎光，地面是很浅的暖灰水泥，没有接缝。没有灯具、木地板、长凳和颗粒。
- **树影**：两层位图（远的大而虚、近的小而清楚），按 17 秒和 9 秒的不同节奏晃；侧墙和地面各有一层更淡的。不透明度 6–17%，只是一点气氛。
- **平墙 `Wall`**：同样的光与树影，不做三维，用来放整面的大字。
- **挂法**：墙上内容按 1 倍写，再用 `zoom` 放大到墙上。`Room` 按墙的实际大小算出缩小系数 `--auto`，整组最多占正墙宽 84%、高 76%，四周一定留白。作品后面有一片「作品灯」的柔光斑。
- **层次与阴影**：

| 东西 | 做法                                                                                    |
| ---- | --------------------------------------------------------------------------------------- |
| 展签 | 白底，4px 圆角，`0 1px 1px rgb(0 0 0 / .05), 0 10px 20px -12px rgb(40 30 20 / .32)`     |
| 卡牌 | 白底，18px 圆角，一圈 7% 墨线加长而软的落影，里面再一圈细框                             |
| 浮层 | 白底，16px 圆角，`0 0 0 1px rgb(27 26 24 / .06), 0 24px 48px -24px rgb(40 30 20 / .35)` |
| 画框 | 浅橡木、白漆、黑铝三种，内衬一圈宽白卡纸                                                |

- 光永远从上方来，阴影向下落。
- **窄屏（900px 以下）**：展厅收成一面平墙加一截浅色地面，作品居中挂，展签放到墙下面，不要白底和阴影。

## 8. 动效

- **只用原生滚动**，不劫持。滚动进度写进 CSS 变量，由样式决定怎么用：`pin`（高于一屏的粘性舞台）、`pass`（整段穿过视口）、`enter`、`leave`；`--d` 是镜头推近的程度，`--lab` 是展签浮现的程度。
- **缓动**统一 `cubic-bezier(0.2, 0.7, 0.1, 1)`：开头快、收尾很慢，像镜头停稳。
- **时长**：悬停 0.25s；下拉 0.4s；进入视口淡入 1s、上移 18px 用 1.2s；卡牌发牌 1.1s，依次错开 90ms；树影 9–21s 一个来回。
- **悬停**只做小动作：顶栏「聊一聊」上浮 1px、卡牌抬起 10px 并倾斜几度、下一间展厅的名字右移 8px。
- **循环动画**离开视口或页面隐藏时要停。
- **减少动态**（`prefers-reduced-motion`）：所有动画停在完整的结果上，粘性编排取消，内容照常可读、可点。
- 作品的动画把「结果」写成基础样式，关键帧只负责过程。这样减少动态时停在结果上，而不是空白。

## 9. 内容与诚实

- 文案全部来自 `content/`，不新增产品事实；原文不随品牌或版式调整改写。
- 诚实标注原样保留：规划中、概念设计、示意、示例数据、界面示意、概念稿。
- 展览隐喻（Room n、媒介名、Installation view）只是装饰，用 `aria-hidden` 或一看就是装饰的写法，不当作产品说法。
- 品牌名始终是 Molis AI。原图形 Logo 不改像素、不滤色。
- 还没开放的产品、OAuth 与邮件功能不能伪装成可用。
- 图片用 `public/` 里已有的图（原生 `img`，声明宽高，按需 `loading="lazy"`）；新画面用 DOM、SVG、CSS 画，不新增依赖。

## 10. 无障碍与响应式

- **断点**：1680 / 1360 / 1140（墙上挂画比例）、900（展厅变平墙、多栏变单列、顶栏换行）、520（隐藏 Logo 文字、页尾两栏）；另有高度 760px 以下的宽屏单独调挂画比例。
- 390px 无横向溢出；长墙这类横向内容在窄屏用自己的横滑容器。
- 键盘都能走到，焦点框 1.5px `ink`、偏移 4px、4px 圆角。
- 按钮与导航项至少 36px 高，文字链接 30px；手机上的主要行动建议 44px。
- 对比度：正文用 `ink` 或 `ink-2`；`mute` 只给辅助信息；杏橙不写小字，要写就用 `accent-ink`。
- 每页一个 h1，标题层级不跳级。

## 13. Do / Don't

**Do**

- 让墙和作品说话，字退后一步；一屏只放一件事。
- 用字号、深浅和留白分层级。
- 杏橙只做点：圆点、细线、淡底。
- 诚实标注原样放在原位。
- 减少动态时停在完整的结果上。

**Don't**

- 不用 600 以上的字重，不用衬线字体，中文不斜体。
- 不给英文标题全大写，不给 300 字重配 18px 以下的字。
- 不加灯具、木地板、颗粒、纹理这类「质感道具」；不加第二种界面颜色。
- 不劫持滚动，不用视差打断阅读区和表单。
- 不在字阶之外随手加新的大字号。
