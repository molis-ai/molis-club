# E2 整站：设计记录

2026-10-13。用户喜欢第四轮 E（`/demos/brand/r4/e`，「玩心造物」）的首屏，但觉得整体太卡通，要求「保留原版，再做一版」并且「给人一种你们是专业的感觉」。先做了同内容的专业版首页 `/demos/brand/r4/e-pro`；随后用户要求按 Folio 最新版 baseline 的全部页面内容，用这一视觉风格做一套完整官网，各页按自己想传达的东西调整布局与动效。本地预览，未提交、未发布。

入口：`/demos/brand/e2`。（10/13 提交时补记：专业版首页 `r4/e-pro` 按用户要求删除、不提交；第四轮的 `r4/e` 已随比稿搬到 `/demos/brand/pitch/e2`，即比稿里的「E · 二稿」，与本站的「E2 整站」不是同一个地址。下文保留当时的写法。）所有页面都在这个目录下，互相链接只在 E2 内部跳转（社区也收进来，不跳回 Folio 或 `/demos/community`）。

## 1. 从「卡通」到「专业」改了什么

| E 原版（卡通感来源）                       | E2                                                      |
| ------------------------------------------ | ------------------------------------------------------- |
| Unbounded 800 宽黑体、描边的橙色「AI」     | Geist 600，字距收紧；「AI」只换成杏橙，不描边           |
| 2.5px 墨线、3–6px 硬投影按钮与卡片         | 1px 细线；按钮实心墨色或细描边，无投影                  |

## 2. 视觉系统（`e2.css`、`shell.tsx`、`axo.tsx`）

**色**：纸 `#fafaf8`、白 `#fff`、墨 `#17171b`、次墨 `#3f3f45`、灰字 `#74737a`、细线 `rgb(23 23 27/.12)` 与 `.22`、图版底 `#f2f1ed`。强调只有杏橙 `#e2875a`（文字用 `#b65a2c`），每块最多一两处：当前栏目的小圆点、眉题圆点、状态签第一枚、轴测图里每件产品的一处。不用杏橙做大面积底色。

**字**（10/13 第二轮改圆润）：拉丁字母 Nunito（圆头），中文 Chiron GoRound TC（圆体黑，200–900；已核对全站文案 1364 个汉字都在字库里），编号、标签、注记、图注用 DM Mono。三者合成一个 `--round` 字体栈，`--display`、`--sans`、`--cjk` 都指向它。Chiron 是港式繁体字库、标点居中，所以用一个 `unicode-range` 字体 `E2 SC Punct` 把中文标点交给系统简体字体（PingFang / 冬青 / 雅黑 / 思源），标点落在左下。大标题 600、字距 −0.02 到 −0.035em（Nunito 比 Geist 宽，字距放松）。正文 16–18px、行高 1.75–1.9，阅读宽度 ≤ 38em。

**线与面**：分区用 1px 线（重要的分区顶边用墨色，其他用浅线）；圆角跟着字变圆：标签 4px、按钮与图版 8px、卡片 12px。图版（`Plate`）是浅灰底 + 细框 + 下方等宽图注「Fig. 0x — 说明 / 诚实标注」。

**编号**：每页的段落、步骤、条目都有两位编号（01、02…），等宽小字。顶栏栏目也编号（01 产品 … 05 团队）。

**轴测图**（`axo.tsx`）：等轴测投影的 `Face`、`Box`、`Line`、`Callout`，三档灰面（顶面白、右前面 `light`、左前面 `side`/`dark`），剖切面 `cut` 涂实，强调 `accent`，光 `glow`。画法统一、内容各页自画：每页可以用这些原语画一张属于本页的图（例如 Tool 的光标与选区、Life 的居家一角、Story 的门与远景、World 的小岛、合作页的流程模型）。线宽用 `--sw` 按取景缩放调到约 1px。svg 加 `data-draw` 时进入视口线描进场（父级或自身带 `.is-in` 时播放）。可点的物件包成 `<a className="e2-spot">`，悬停时自己的标注变墨色、其余退淡。

**部件**（`shell.tsx`）：`E2Page`（根节点 + 顶栏 + 正文 + 页尾，`footer` 放本页结尾，`compactFooter` 用于短页）、`Header`（`current` 标当前栏目）、`Footer`、`useE2Motion`（`data-scene` 写 `--p`，`data-reveal` 加 `is-in`，根节点 `is-scrolled`）、`useStepper`（视口中线决定 `data-step`）、`Phrases`（中文按标点成组不折断）、`Kicker`、`Tag`、`Status`、`Button`/`Actions`（ink 实心每处最多一个；ghost 描边；light 用在深色块；text 文字链接）、`SectionHead`（编号 + 眉题 + 大标题，`split` 时导语在右）、`Plate`、`NextProduct`。表单输入用 `.e2-field`。

**克制的玩味**：只在访客动手时回应，不自己循环——Logo 悬停转四分之一圈、按钮按下轻轻一沉、轴测图里可点的物件悬停抬起一点（首页房间里：光标像点了一下、门里的光变亮、灯光更暖、屏幕亮起）、眉题圆点在区块悬停时放大、选中文字带杏橙底。各页本身的可玩之处（Tool 的选中翻译、Life 的例子切换、Story 的穿门、World 的小岛长大、社区的小花）保留。

**动效原则**：动效服务于「看懂」，不做装饰。允许：淡入上移、线描进场、滚动驱动的画面切换（粘性舞台 + `data-step`）、界面示意里的状态推进（自动播放要在离开视口或页面隐藏时停止，并给暂停）。禁止：回弹、旋转、硬投影、无意义的循环小动画、劫持滚动。减少动态时一律直接给最终画面、取消粘性编排。

**诚实**：文案全部来自 `content/`，不改原文、不编事实。界面示意标「界面示意 · 示例数据」，概念稿标「概念稿 / 概念画面 / 概念示意 / 示例旅程」，规划中的能力标「规划中」。没有的功能不做成可用的样子。

## 7. 第三轮（2026-10-13 下午）：回到最初版 E2 的设计思路

用户看了改圆润后的整站，觉得首页「本来挺好的」被改没了；澄清后要求：**以最初版 E2 首页（r4/e）的设计思路和风格为底**做完其他页面；各页按内容适配，面向客户的页面更专业；整体统一，但动效与布局按各页想传达的来，可以有差异；动效和画面都为了更好地传递内容；**字体保留圆润这一版**。

- 首页：换回 r4/e 原版——线描工作室首屏（排线、悬停浮出名牌）、四张牌随滚动摊开、Work 四格漫画、「你正在好奇什么？」大字配大圆与竖排入口（`page.tsx`、`home-room.tsx`、`home.css`，类名沿用 `we-`）。只改了：字体换成圆润的一套（字标 Nunito 900 + 描边橙色 AI），链接指向 E2 自己的页面，顶栏与页尾用整站共用的那一份。
- 共用系统（`e2.css`、`shell.tsx`）改回 E 的样子：
  - 顶栏是 E 的每栏一个线描图标 + 等宽小字（产品栏列出五件产品），当前栏目名字下一道杏橙、当前产品前一个杏橙点；滚过顶栏后顶部滑下一条细快捷栏（Logo、产品下拉、四个栏目、聊一聊），长页面随时能跳走。
  - 墨色 `#121212`、白纸 `#fdfdfb`、杏橙 `#ea9260`；重要分区 1.5px 墨线。眉题是墨色小签，状态签是 1.5px 墨线胶囊（第一枚杏橙底），按钮带 3–4px 硬投影（墨色按钮配杏橙影、描边按钮配墨影），图版是墨线框 + 网点底。
  - 轴测图统一成首页的画法：侧面斜排线、暗面与剖切面反向密线（`HatchDefs` 全页共用），白面、墨线加粗到约 1.5px，标注是墨线小牌、编号杏橙。各页原有的图（Life 的居家一角、Story 的拱门长廊、World 的小岛、合作页的流程、联系页的收件箱……）因此都和首页同一手笔。
  - 产品页末尾「接着看」左边加一张首页牌堆里的牌（W / T / L / S，World 是 O），微微歪着，指上去摆正。
  - 标题加粗：各页首屏大标题 700，「Team」「Essays」这类英文大字 800，大句与中等标题至少 600。
- 面向客户的页面（Work、解决方案、联系、团队、文章）保持规整的表格、步骤与少量动效；探索类页面（Tool、Life、Story、World、社区）保留各自的交互与滚动画面。
- 验证：`tsc`、`oxlint`、`npm run build`、`npm test`（23）通过；48 个页面全部 200、各一个 h1、链接与锚点都在 E2 内；按访客路径点击走查（含新顶栏的产品小字、快捷栏的产品下拉、Logo 回首页）全部通过；1440 与 390 无横向溢出。

## 8. 第四轮（2026-10-13 傍晚）：专业不等于少动效

用户澄清：专业不代表少动效；要漂亮、有设计感的页面，动效不花哨但要恰当，帮人理解当下想表达的内容，可以配合交互。据此补了面向客户的三页（Work 原本就有演示与滚动场景，不再加）：

- **解决方案**
  - 首屏流程图：线描画完后，一张「问题」纸沿流程走过三站（一起说清楚 → 业务经验 ＋ Agent 执行 → 亲手跑通、亲自验收 → 继续往前），走到哪站，那站的物件、引线与图例亮起，其余退淡；指到或用键盘聚焦图例可停在那一站。
  - 四件事：每行进入视口时，箭头从「情况」画到「怎么做」再到「一起做到」，结果框落定（墨线 + 杏橙影），读出「从问题到能力」的转化。
  - 做这件事的人：指到一个人，四列里他出现的地方一起亮。
  - 「执行交给 Agent，关键判断留给人」：一条小跑道，Agent 的点往前做事，走到付款、发布、报价、权限、重要决定这些关口停下「等你确认」，打勾后再走；进入视口才开始，走完可重播，离开视口暂停。
