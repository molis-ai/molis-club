# 第三轮：A / D / E 三个方向的首页

2026-10-11。用户把方向收敛为 A（暖纸与画框）、D（日光与生活）、E（玩心造物），要求以 `/demos/brand/folio` 首页的内容为基线，学习每个方向全部参考站的动效、设计、表达与布局，结合工作室的调性、理念与愿景重新设计。本地预览，未提交、未发布。

入口（2026-10-12 并入首页视觉方向比稿 `/demos/brand/pitch`）：`/demos/brand/pitch/a1`、`/demos/brand/pitch/d1`、`/demos/brand/pitch/e1`，原 `/demos/brand/r3` 系列地址已撤下。内页（产品、方案、文章、社区、团队、登录、联系）沿用 Folio 现有页面。

## 研究

- 21 个参考站（A 7、D 6、E 8，名单来自情绪板 `data.js`）：先读既有整页拼板，再用无头浏览器逐站采样首屏 0.4 / 1.2 / 2.5 / 4.5 秒四帧与前 3600px 每 300px 一帧，并记录滚动时变化的元素、动画库、关键帧、字体与粘性元素。拼板与原始数据存于 `research/molis-design-moodboard/motion-2026-10-11/`。
- 采样是主页首段的视觉与动效机制，不是完整交互体验；视频内容、悬停细节与长页尾部以既有整页拼板为准。

## 内容基线

与 Folio 首页同一份：`content/folio.ts`、`content/studio.ts`、`content/folio-work.ts`、`content/molis-tool.ts`、`content/molis-work.ts`。首屏只有 Molis AI、A/I 词组与「好奇 · 创造 · 人的尺度」，不加口号；产品四件、结尾两条去处与页尾栏目一一保留。唯一新增展示的是 `folioHomeCopy.description`（Folio 已有的首页简介，原用于页面描述），A 写成一封信，D 写成白墙上的自述。E 的摇柄步骤说明由 Work 演示的原有内容拆出。

## 诚实标注

- Work、Tool 演示为「界面示意 · 示例数据」，不连接真实 Agent；v0.2.0 与开发中的 0.3.0 区分。
- A 的油画、D 的照片、E 的线描都是氛围或概念图，按 Folio 原有说法标注「概念稿」「概念画面」，其余标「氛围图」「插画」；照片不是团队纪实或用户证言。
- 原 Molis Logo 不改像素、不改色；深色背景上作为圆角小方签放置。

## 实现

`kit.tsx`（顶栏与产品菜单、滚动驱动、按中线步进、逐字显影、演示外壳）与 `sheets.tsx` / `sheets.css`（A、D 共用的 Work、Tool 演示时间轴）共用；各方向的皮肤、版式和专属零件在各自目录。没有新增依赖，没有改动 Folio、共享内容或后端。所有演示进入视口才播放、可暂停、切到后台即停；减少动态时停在完整结果，粘性编排改为普通排列。

## 验证

- `tsc --noEmit`、`oxlint`（r3 目录）、`npm run build`、`npm test`（19 项）通过。
- 无头浏览器以静态打包方式（不经本地服务）检查：1440 与 390 宽度整页、减少动态、三页文案与链接和 Folio 首页逐项一致、无横向溢出、无破图；E 的摇柄自动、点击、拖动、方向键、回车与读屏播报均实操。
