# 第五版：夜间展馆

2026-10-11。用户想要一版更高级、更有质感和沉浸感、「像逛展」的首页，并请我看看还有哪些风格意向。本版把首页做成一场展览，内容仍按 Folio 首页组织。本地预览，未提交、未发布。入口：`/demos/brand/pitch/night`（2026-10-12 并入首页视觉方向比稿，原 `/demos/brand/r5` 已撤下）。

## 看过的意向

补看 8 个站点（首屏随时间的帧与滚动帧，存于 `research/molis-design-moodboard/motion-2026-10-11/`）：teamLab、Refik Anadol、Igloo、Lusion、Apple Vision Pro、Gagosian、21_21 DESIGN SIGHT；Studio Drift 出现人机验证，未读取。归纳出四条路子：

1. 夜间展馆（teamLab、Refik Anadol、Igloo）：暗场、光点亮作品、滚动就是往前走。
2. 白盒子美术馆（Gagosian、21_21）：近白展墙、窄体衬线大标题、展讯式清单，靠克制与秩序取胜。
3. 空间叙事（Lusion、Vision Pro）：门户式画框放大成空间、带透视的卡片、贯穿全页的线。
4. 数字装置（Refik Anadol）：每件作品本身是一件会动的光影装置。

本版做 1，并融入 4。

## 展览动线

- 前厅：展名墙上的「Molis AI」被一束光扫亮，A/I 词组作展览副题，三个关键词作章节；右侧是前言（`folioHomeCopy.description`）。往下走，中间的入口放大，把人带进第一展厅。
- 展厅 01 · Work：一块发光的屏幕装置（复用第三轮的演示时间轴，换成暗厅皮肤），地面有倒影。
- 展厅 02 · Tool：投影文字。一句英文投在墙上，一道光划过它，旁边浮出三个动作，译文由模糊到清晰。
- 展厅 03 · Life：霓虹静物——扶手椅、落地灯、小茶几上一杯热茶，进场时逐笔亮起。
- 展厅 04 · Story：一道发光的门，门里起雾，光粒慢慢飘出来。
- 出口：「你正在好奇什么？」与两张服务台（合作、社区），然后是页尾。

每个展厅固定在视口里，随滚动开灯、看展、熄灯；鼠标是一束手电光，展厅随它轻微转动（三维视差）；左下角的平面图标出当前所在的展厅，可以点击跳转。

## 诚实标注

Work、Tool 为「界面示意 · 示例数据」；Life、Story 标「概念稿」「概念画面」。装置是代码绘制的光影，不代表产品界面或硬件外观。原 Logo 不改像素。

## 实现与验证

`page.tsx`、`exhibits.tsx`、`x.css`，字体在 `layout.tsx`（Cormorant Garamond、Noto Serif SC）。复用 `r3/kit.tsx` 与 `r3/sheets.tsx`，没有新增依赖，没有改动 Folio、共享内容或后端。减少动态时灯一直亮着、展厅不再固定；900px 以下展厅改为一间间往下走。

`tsc --noEmit`、`oxlint`、`npm run build`、`npm test`（19 项）通过；无头浏览器以静态打包方式检查 1440 与 390 宽度，文案与链接和 Folio 首页逐项一致、一个 h1、无横向溢出、无破图。真实 dev 服务上的观感、Safari（`-webkit-box-reflect` 倒影仅 WebKit/Chromium 支持，Firefox 无倒影）与真机触摸仍待用户验收。
